## 表4-场景登记字段

表 4　图像级场景与来源登记字段

建议 SOP｜unknown 显式保留；来源陈述、视觉观察与推断分开

| 字段组 | 建议字段 / 值 | 登记规则 | 验收要求 |
|---|---|---|---|
| 来源和版本 | dataset、image_relpath、sha256<br>source_url、annotation_version | 路径 + 内容 hash 绑定图像<br>记录原始名称与项目别名 | 任一图可追溯到<br>批准的标签版本 |
| 拍摄环境 | site_id；indoor / semi_open /<br>outdoor / web / mixed / unknown | web 是来源类别，不是场地<br>网页图像仍可有 indoor 标签 | 环境与来源分字段<br>证据定位可打开 |
| 机位和镜头 | camera_id；top / oblique / side<br>height_m；fisheye / unknown | 型号 / 高度取一手元数据<br>无畸变外观不等于证实透视 | 未知项保留 unknown<br>不反推相机型号 |
| 光照与模态 | daylight / artificial / low_light<br>RGB / NIR / thermal / unknown | 低照度是现象，不等于 NIR<br>NIR 辅助与热成像分别记录 | 每个模态标签有<br>论文或设备依据 |
| 时序与关联组 | video_id、time_block、cow_id<br>derivative_group、source_group | 按评估目标定义关联约束<br>原图 / 变体 / 近重复同组 | 组交集与泄漏审计<br>报告为可检查清单 |
| 尺度与拥挤 | image_W/H；box_w/h；cow_count<br>area_ratio；occlusion；truncation | 尺度由当前批准框计算<br>遮挡给可见证据或 unknown | 统一口径；原图与<br>640 输入尺度分记 |
| 标注与证据 | HBB / OBB；torso / whole<br>visible / inferred；evidence_ref | 格式、目标范围、遮挡规则<br>拆开记录；不把转换等同重标 | 多复核员冲突保留<br>批准后再进入评估 |

上述字段为本次设计建议，尚未对原始图像包批量填充；核查方法参考 W11–W15。
