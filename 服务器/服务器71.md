###  **ssh -N -L 是 SSH 端口转发的核心参数，逐个解释：**

  完整命令拆解

  ssh -N -L 8888:localhost:8888 -p 55522 yxli@211.69.141.71

  -L（Local，本地端口转发）⭐ 核心

  格式：-L 本地端口:远程目标:远程端口

  -L 8888:localhost:8888 的意思是：
  - 在你本地机器开一个端口 8888
  - 任何发到本地 8888 的流量，都通过 SSH 隧道转发到远程服务器上的 localhost:8888

  ▎ 这里的 localhost 是站在远程服务器视角说的--指的是远程服务器自己的 8888 端口（也就是
  ▎ JupyterLab 监听的那个）。

  三个部分：

  ┌──────────┬───────────┬────────────────────────┐
  │   部分   │    值     │          含义            │
  ├──────────┼───────────┼────────────────────────┤
  │ 本地端口 │ 8888      │ 你电脑上要开的端口     │
  ├──────────┼───────────┼────────────────────────┤
  │ 远程目标 │ localhost │ 转发到远程服务器的本机 │
  ├──────────┼───────────┼────────────────────────┤
  │ 远程端口 │ 8888      │ 远程 JupyterLab 的端口 │
  └──────────┴───────────┴────────────────────────┘

  -N（No command，不执行远程命令）

  告诉 SSH 只建立隧道，不打开
  shell。因为我们的目的纯粹是转发端口，不需要在远程跑命令。如果省略 -N，SSH
  会建隧道的同时还尝试登录 shell（你看到的就是卡住等命令输入）。

按下Ctrl+d或者显式输入exit命令，就可以退出 Tmux 窗口

**离开 session**
有时候我们需要离开终端，操作其他的任务，需要离开该任务，但是又想该任务继续在后台执行，这时候我们需要在 tmux 的任何一个窗格中输入如下命令：

tmux detach

**查看 session 列表**
有时候我们可能同时操作了好几个 session， 我们可以通过如下的命令来查看我们目前操作了几个session：

tmux  ls  

**进入 session**
离开 session 之后，有时候我们还需要对某个 session 进行操作，这时候可以通过如下的操作：

tmux attach -t  <session-name>

**关闭 session**
如果需要关闭 session, 可以通过执行如下的命令即可：

tmux kill-session -t <session-name>

**切换 session**
执行命令,可以从当前的 session 快速切换到另一个 session：

tmux switch -t <session-name>

**重命名 session**

tmux rename-session -t <old-session-name> <new-session-name>
