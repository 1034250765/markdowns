# 数据集融合方法：Fusion or Confusion?（CVPR 2025 Workshop）

## 1. 论文信息

- **标题**：*Fusion or Confusion? A Look at Dataset Pooling for Infrared Object Detection*
- **作者**：Stefan Becker、Ann-Kristin Grosselfinger、Jens Bayer、David Munch、Wolfgang Hubner、Michael Arens
- **单位**：Fraunhofer IOSB、Fraunhofer Center for Machine Learning
- **会议**：CVPR 2025 Workshop，21st Workshop on Perception Beyond the Visible Spectrum（PBVS 2025）
- **研究任务**：红外图像中的车辆目标检测
- **DOI**：[10.1109/CVPRW67362.2025.00428](https://doi.org/10.1109/CVPRW67362.2025.00428)
- **论文主页**：[CVF Open Access](https://openaccess.thecvf.com/content/CVPR2025W/PBVS/html/Becker_Fusion_or_Confusion_A_Look_at_Dataset_Pooling_for_Infrared_CVPRW_2025_paper.html)
- **论文 PDF**：[CVF PDF](https://openaccess.thecvf.com/content/CVPR2025W/PBVS/papers/Becker_Fusion_or_Confusion_A_Look_at_Dataset_Pooling_for_Infrared_CVPRW_2025_paper.pdf)
- **补充材料**：[Supplementary Material](https://openaccess.thecvf.com/content/CVPR2025W/PBVS/supplemental/Becker_Fusion_or_Confusion_CVPRW_2025_supplemental.pdf)

> 这篇论文不是提出一种新的特征融合网络，而是系统研究 **Dataset Pooling（数据集池化/数据集融合）**：把多个数据集统一标签后合并训练，分析这种做法什么时候有效、什么时候会因域差异而产生负面作用。

## 2. 研究目的

红外目标检测数据集通常规模较小，收集和标注新数据的成本较高。一种直接扩大训练数据的方法，是将多个已有数据集合并，以增加样本数量、场景多样性和类内变化。

但是，不同数据集可能来自不同的：

- 传感器和图像处理流程；
- 拍摄高度与观察视角；
- 温度、天气和环境条件；
- 图像分辨率、动态范围与噪声水平；
- 标注类别体系和标注风格。

因此，更多数据并不必然带来更好的泛化能力。论文主要回答以下问题：

1. 多个红外数据集合并训练，是否稳定优于单数据集训练？
2. 同域融合与跨域融合的效果有何差异？
3. 图像预处理能否减小不同红外数据集之间的域差异？
4. 能否通过特征分布或 Dataset Affinity Score（DAS）判断哪些数据适合融合？
5. 融合模型在未参与训练的新数据集上能否获得更好的零样本泛化能力？

## 3. 主要方法

### 3.1 标签统一

不同数据集包含 `car`、`bus`、`truck`、`van`、`freightcar` 等不同车辆子类别。作者将这些子类别统一映射为一个上位类别：

```text
car / bus / truck / van / freightcar / ... -> vehicle
```

这样可以解决不同数据集类别体系不一致的问题，并构建一个单类别红外车辆检测器。

### 3.2 数据集及数据池划分

论文使用了 7 个公开红外数据集，其中 5 个参与训练，2 个只用于零样本测试。

| 数据域 | 数据集 | 是否进入训练池 |
|---|---|---|
| 地面视角 | FLIR v2 | 是 |
| 地面视角 | M3FD | 是 |
| 地面视角 | MCNet | 否，仅零样本测试 |
| 航拍视角 | DroneVehicle | 是 |
| 航拍视角 | TrafficNight | 是 |
| 航拍视角 | HIT-UAV | 是 |
| 航拍视角 | WIT-UAS | 否，仅零样本测试 |

训练数据池分为：

- **Ground 池**：FLIR v2 + M3FD；
- **Aerial 池**：DroneVehicle + TrafficNight + HIT-UAV；
- **All 池**：以上 5 个训练数据集全部合并。

作者同时训练单数据集模型，比较“单数据集、同域池、全量池”三种策略。

### 3.3 检测模型与训练设置

- 检测器：YOLOv9-C；
- 初始化：MS COCO 预训练权重；
- 训练轮数：150 epochs；
- 指标：`mAP@0.5` 和 `mAP@0.5:0.95`；
- 对照实验：完全微调骨干网络与冻结骨干网络；
- 数据平衡：对固定机位序列进行下采样，以减少重复背景造成的过采样。

### 3.4 红外图像预处理

作者尝试用三种方法统一不同数据集的图像对比度：

- HE：全局直方图均衡化；
- CLAHE：限制对比度的自适应直方图均衡化；
- FieldScale：面向热红外图像的局部自适应重缩放方法。

实验比较原始图像和三种预处理图像在 All 数据池上的检测效果。

### 3.5 数据集关系分析

作者采用两类分析方法：

1. 使用 CLIP 提取图像特征，再通过 t-SNE 将特征降到二维空间，观察各数据集的聚类和距离；
2. 使用 Dataset Affinity Score（DAS），预测每个检测结果更接近哪个训练数据集。

## 4. 关键实验结论

### 4.1 数据集融合通常有帮助，但不是数据越多越好

增加训练数据的数量和多样性通常可以提高模型鲁棒性，但全量池并不总是最佳组合。同域的小型数据池经常可以达到甚至超过 All 池。

部分 `mAP@0.5:0.95` 结果如下：

| 测试集 | 单数据集模型 | 同域数据池 | All 数据池 | 现象 |
|---|---:|---:|---:|---|
| FLIR v2 | 0.522 | Ground：0.529 | 0.513 | Ground 最好，全量融合下降 |
| M3FD | 0.628 | Ground：0.632 | 0.612 | Ground 最好，全量融合下降 |
| DroneVehicle | 0.601 | Aerial：0.602 | 0.601 | 三者基本相当 |
| TrafficNight | 0.564 | Aerial：0.566 | 0.563 | Aerial 略好 |
| HIT-UAV | 0.669 | Aerial：0.696 | 0.703 | All 池最好 |

这些结果说明：

- 域相近的数据可以互相补充；
- 跨域数据可能带来有用多样性，也可能产生干扰；
- 数据池的组成比数据池的绝对规模更重要；
- 使用更少但更匹配的数据，可能达到与全量池相当或更好的结果。

### 4.2 零样本实验进一步证明“全量融合不一定最好”

MCNet 和 WIT-UAS 没有加入训练，只用于测试模型对未知数据集的泛化能力。

在 WIT-UAS 上：

- TrafficNight 单数据集模型：`0.219`；
- Aerial 数据池：`0.214`；
- All 数据池：`0.217`。

一个单数据集模型略微超过了全部融合模型。这说明训练池虽然变大了，但新增数据并没有充分覆盖 WIT-UAS 的目标分布。

### 4.3 地面视角和航拍视角之间存在明显域差异

地面数据训练的模型在航拍测试集上通常表现很差，航拍数据训练的模型在地面测试集上也有类似问题。原因包括：

- 摄像机高度不同；
- 目标尺度和长宽比不同；
- 观察角度不同；
- 背景结构不同；
- 传感器和图像处理方式不同。

因此，融合之前应先按照视角、设备或场景进行域划分。

### 4.4 传统预处理没有带来稳定收益

HE、CLAHE 和 FieldScale 对论文使用的低动态范围公开红外图像基本没有显著提升，有时还会降低性能。例如在 FLIR v2 上：

| 输入形式 | mAP@0.5:0.95 |
|---|---:|
| 原始图像 | 0.513 |
| HE | 0.497 |
| CLAHE | 0.496 |
| FieldScale | 0.505 |

作者认为，现代检测器可能已经能够在特征学习过程中补偿部分对比度差异。需要注意的是，这一结论针对的是已经被处理成低动态范围的公开图像，不能直接推断预处理对原始全动态范围红外数据也无效。

### 4.5 完全微调优于冻结骨干网络

在所有测试数据上，完全微调骨干网络普遍优于冻结骨干。这说明模型需要调整底层和中层视觉特征，才能适应红外图像及多数据集分布。作者没有观察到完全微调导致明显的单数据集过拟合。

## 5. Dataset Affinity Score（DAS）详解

### 5.1 DAS 要解决的问题

DAS 是 Dataset Affinity Score，即“数据集亲和度分数”。它试图回答：

> 对于当前测试图像中的一个检测目标，它在视觉分布上更接近训练池中的哪一个数据集？

普通检测器只需要预测目标框、目标置信度和语义类别。加入 DAS 后，模型还要预测每个检测结果的数据集来源。

例如，一个检测框可能得到如下数据集亲和度：

```text
FLIR          0.55
M3FD          0.30
DroneVehicle  0.08
TrafficNight  0.05
HIT-UAV       0.02
```

这表示该目标的视觉特征与 FLIR 数据域最接近。

### 5.2 DAS 如何训练

训练池中的每个目标除了有位置和 `vehicle` 标签，还天然具有一个“来源数据集”标签。例如：

```text
目标类别：vehicle
数据来源：FLIR
```

模型由此学习不同数据集的域特征，例如：

- 地面视角或航拍视角；
- 目标在图像中的尺度；
- 红外对比度和传感器噪声；
- 背景、道路和拍摄环境；
- 数据集特有的成像及标注特征。

原始 DAS 方法使用额外的分类头预测数据集来源。本文因为只检测一个统一类别 `vehicle`，所以直接使用默认分类头预测数据集来源，而没有增加第二个分类头。

### 5.3 单目标与整个测试集的 DAS

对于检测框 (x)，模型输出它对第 (k) 个训练数据集的亲和度 (p_k(x))。可将最高分的数据集作为该检测框的归属：

$$
a(x)=\arg\max_k p_k(x)
$$

再对一个测试集中的全部检测框进行统计：

$$
A_k=\frac{N_k}{N}
$$

其中：

- (N) 是该测试集上的检测框总数；
- (N_k) 是被归到第 (k) 个训练数据集的检测框数量；
- (A_k) 表示该测试集对第 (k) 个训练数据集的总体亲和比例。

如果一个测试集上的绝大多数检测结果都被分给少数几个训练数据集，说明其他数据集对这个测试域可能帮助有限，可以考虑构建一个更稀疏的数据池。

### 5.4 论文中的 DAS 现象

- 对航拍测试集 WIT-UAS，检测结果主要被分配给其他航拍训练数据集；
- 对地面测试集 MCNet，检测结果主要与地面训练数据集相关；
- 该结果符合地面域与航拍域的实际差异，也可以作为 DAS 的合理性检查；
- DAS 揭示的信息不一定能从 CLIP+t-SNE 图中直接看出来。

因此，DAS 能帮助发现：

- 哪些训练数据与目标测试域更匹配；
- 哪些数据可能基本没有贡献；
- 哪些数据集存在冗余；
- 全量融合为什么没有超过同域数据池。

### 5.5 DAS 的局限

#### DAS 不是因果贡献度

一个检测结果被分配给 FLIR，不表示该检测只由 FLIR 数据产生。模型参数是由整个训练池共同优化的，DAS 只表示视觉分布上的亲和性。

#### DAS 不是可直接使用的融合适合度公式

DAS 可以筛选候选组合、解释域关系，但不能单独证明某个组合一定会提高 mAP。最终仍需重新训练和评估。

#### DAS 可能降低检测精度

论文表 3 的零样本结果显示：

| 测试集 | 不使用 DAS | 使用 DAS |
|---|---:|---:|
| MCNet | 0.681 | 0.663 |
| WIT-UAS | 0.217 | 0.175 |

数值为 `mAP@0.5:0.95`。要求模型同时区分目标和数据集来源，可能增加学习难度，并使模型更加关注域差异。因此，DAS 在本文中更适合作为解释和诊断工具，而不是直接提升精度的模块。

### 5.6 DAS 的正确使用方式

论文隐含的实际流程是：

1. 训练带 DAS 的全量数据池模型；
2. 在目标测试域或零样本数据集上统计亲和度分布；
3. 找出亲和度高的数据集和可能冗余的数据集；
4. 据此构造更小的候选数据池；
5. 重新训练普通检测器；
6. 用真实 mAP 判断新组合是否更好。

即：**DAS 用于缩小搜索范围，检测性能用于最终裁决。**

## 6. 论文怎样判断融合是否合适

本文没有给出一个能够自动判断融合适合度的单一公式，而是综合使用以下证据：

1. **检测性能**：比较单数据集、同域池和 All 池的 mAP；
2. **零样本泛化**：在完全未参与训练的数据集上测试；
3. **DAS**：分析检测结果主要与哪些训练数据集亲近；
4. **CLIP+t-SNE**：辅助观察数据集间的特征分布差异；
5. **消融实验**：比较预处理、冻结骨干和完全微调等训练条件。

其中，真实检测性能是最终标准。作者特别指出：低维特征距离可能具有误导性，DAS 也只能提供候选方向，不能替代重新训练和评估。

## 7. 创新点

这篇文章的贡献主要是实验设计和评估框架，而不是提出新的检测网络：

1. 系统比较单数据集、同域数据池和跨域全量数据池；
2. 在 7 个红外数据集上同时考察域差异、预处理和零样本泛化；
3. 使用 CLIP+t-SNE 与 DAS 分析训练数据和测试域之间的关系；
4. 证明“更多训练数据”不等于“更好的目标域性能”；
5. 指出稀疏但匹配的数据池可能比全量数据池更高效；
6. 强调现有相似性分析只能辅助筛选，最终仍需要重新训练验证。

## 8. 对牛只数据集融合的启示

这篇论文的方法可以迁移到多来源牛只检测任务，但需要将“红外车辆数据域”替换为“牛只拍摄数据域”。

### 8.1 先定义数据域

可以按照以下因素划分数据集：

- 农场或地区；
- 相机型号；
- 固定监控、手持拍摄或无人机视角；
- 俯视、侧视、正视或斜视；
- 室内牛舍或室外牧场；
- 白天、夜间、RGB 或红外；
- 近景大目标或远景小目标；
- 遮挡程度、牛群密度和背景复杂度；
- 标注类别和标注边界风格。

### 8.2 设计三组对照实验

建议至少比较：

1. 单数据集训练；
2. 相似域数据融合，例如相似视角或相似农场环境；
3. 所有数据集全量融合。

同时保留一个完全不参与训练的新农场或新相机数据集，用于零样本泛化测试。

### 8.3 将 DAS 用于来源分析

可以把 DAS 的来源标签设置为：

- 数据集名称；
- 农场编号；
- 相机编号；
- 拍摄视角；
- 场景类别。

例如，如果某个新农场上的检测结果几乎全部亲近于两个室内固定相机数据集，那么其他室外或无人机数据可能对该目标域帮助有限。随后可以只使用高亲和度数据构建精简训练池，再通过重新训练验证。

### 8.4 最终判断原则

牛只数据集是否适合融合，不能只看图像数量或特征可视化，应同时满足：

- 目标域 mAP 不下降；
- 未见农场或未见相机上的泛化能力提高；
- 不同来源的标签定义和标注质量一致；
- 新增数据带来的收益能够覆盖训练成本；
- 精简数据池与全量池相比没有明显性能损失。

## 9. 总结

这篇论文最重要的观点是：

> 数据集融合的关键不是“合得多”，而是“合得合适”。数据的域匹配程度和互补性通常比数据总量更加重要。

DAS 可以帮助解释测试数据更接近哪些训练来源，并据此筛选更合理的数据组合；但 DAS 不是严格的因果贡献度，也不能自动给出最优融合方案。可靠流程仍然是：**先用 DAS 和特征分析提出候选组合，再通过重新训练和跨数据集 mAP 测试完成验证。**
