# CowCV 候选数据集评估：综述中标注为「边界框」的牛类数据集

> 评估日期：2026-09-28 ｜
> 标尺来源：《CowCV 文章初稿》3.1 节纳入原则 + 3.3 节标注标准化 + 2.2 节域标签体系
> 候选来源：Bhujel et al. (2025) *Computers and Electronics in Agriculture* 229:109718 表 1（27 个牛类数据集）

## 一、评估标尺（先明确口径）

CowCV 当前检测视图的硬约束：

| 维度 | 要求 | 出处 |
|---|---|---|
| 类别 | **单类 `cow`**，原始多类需合并 | 3.1 节 |
| 框语义 | **整牛水平边界框（HBB）**，可用原始框或重新标注获得 | 3.1 节原则 1、2 |
| 格式 | YOLO 归一化 `class_id x_center y_center width height` | 3.3 节 |
| 规模 | 数量**不是**硬阈值（CImage 176 张亦纳入），但过小需标注解释 | 3.1 节 |
| 标注质量 | 漏标严重的必须复核后再定（CBVD-5 前例） | 3.1 节 |
| 来源独立性 | 与已纳数据集**同源/近重复**的不重复计入 | 3.1 节、CMBN 前例 |
| 许可 | 许可证与**再分发范围**须逐项核验（涉及数据门户） | 3.1 节原则 3 |
| 帧冗余 | 连续视频帧需按来源序列分层抽样 | 2.2 节 |

### 2.1 Cattle-counting — ✅ 强烈推荐

| 项 | 内容 |
|---|---|
| 论文 | Soares, V.H.A., Ponti, M.A., Gonçalves, R.A., Campello, R.J.G.B. (2021). *Cattle counting in the wild with geolocated aerial images in large pasture areas.* Comput Electron Agric 189:106354. DOI 10.1016/j.compag.2021.106354 |
| 获取 | ✅ 官网有效：`vhasoares.github.io/downloads.html`，含 **Whole training dataset** + **BR_set test collection** 两个 Google Drive 链接；另有第三方镜像（Supervisely 格式 3.28 GB） |
| 规模 | 5,058 张航拍图，6 个牧场，带地理参考信息 |
| 标注 | LabelImg 边界框，统一标签 `cattle` → 直接映射 `cow` |
| 采集 | 四旋翼 + 高分辨率相机，5 个高度（80/90/100/110/120 m）× 3 时段（早/午/晚） |
| 场景多样性 | 3 个干燥沙土场地**仅白牛**；3 个红土绿草场地**多色牛**（白/黑/棕/红/花斑） |

**为什么推荐：**

1. **提供真正的独立测试域**——这是它最大的价值。CowCV 目前只有 Cows2021 和 Dairy Cow 保留了原始名义 `test` 划分，而纳入原则第 4 条明确"**原始资源另有独立测试划分时，才将其用于独立测试评估**"。Cattle-counting 的 BR_set 是官方独立测试集，可让 CowCV 多一个不参与训练调参的冻结测试域。
2. **填补"无人机高空航拍"空白**——CowCV 现有最高视角是 XGain 的 6 m 高位俯拍，80–120 m 量级的无人机视角完全没有。
3. **变量控制最严谨**——高度×时段×土壤背景近似正交设计，天然适合分析"尺度变化对检测的影响"，可直接支撑论文中的域分析章节。
4. 标注语义干净（单一 `cattle`），无需类别修正。

**需注意：**

- 5,058 张会使 CowCV 总量从 31,373 → **36,431 张（+16%）**，需评估域平衡影响（见第四节）。
- 原始图 3000×4000 高分辨率需确认与现有预处理管线兼容（YOLO 通常 letterbox 到 640）。
- BR_set 的用途要与训练集严格隔离，避免抽样审计时误入训练池。

### 2.2 Aerial-livestock-dataset — ✅ 推荐（需确认类别语义）

| 项 | 内容 |
|---|---|
| 论文 | Han, L., Tao, P., Martin, R.R. (2019). *Livestock detection in aerial images using a fully convolutional network.* Computational Visual Media 5:221-228. DOI 10.1007/s41095-019-0132-5（清华团队） |
| 获取 | https://github.com/hanl2010/Aerial-livestock-dataset/releases |
| 规模 | 89 张四旋翼航拍图（≈3000×4000），**4,996 个实例**（平均 56 个/图，高密度） |
| 标注 | 边界框，统一标签 `livestock` |
| 难度分级 | **显式三档**：Ⅰ 黑色+简单背景（29 图）/ Ⅱ 黑色+地貌噪声背景（17 图）/ Ⅲ 密集多色+雪地建筑干扰（43 图） |

**推荐理由：**

1. 与 Cattle-counting 形成互补：前者是**高密度小目标**（56 个/图），后者是**大场景计数**，同属航拍但目标密度差异大——正好构成"密集 vs 稀疏"的域对照。
2. **自带难度分级标签**，可直接作为检测鲁棒性的分层分析维度，这类元信息在现有 14 个数据集里没有。
3. 规模小（89 张）不构成负担，且 CowCV 已确立"数量不是唯一阈值"的先例（CImage 176 张）。

**需先解决：**

- ⚠️ **类别语义必须复核**：标签是 `livestock`（牲畜）而非 `cattle`。摘要称"animals grazing on grassland"，需逐图确认是否**混有羊只**。若混入非牛个体，只能从中篩出牛只子集，规模会进一步缩水。
- 与 Aerial Pasture 的场景相似度需审计（同为亚洲草地航拍，见 2.4）。

### 2.3 AerialCattle2017 — ⚠️ 有条件纳入（必须抽帧 + 框质量审计）

| 项 | 内容 |
|---|---|
| 论文 | Andrew, W., Greatwood, C., Burghardt, T. (2017). *Visual Localisation and Individual Identification of Holstein Friesian Cattle via Deep Learning.* ICCVW 2017, pp. 2850-2859. DOI 10.1109/ICCVW.2017.336 |
| 获取 | ✅ `data.bris.ac.uk/data/dataset/3owflku95bxsx24643cybxu3qh`（同域名另两个数据集实测可用） |
| 规模 | **34 段牛群视频（平均约 20 秒）→ 46,430 帧** |
| 标注 | **首帧人工框 + KCF 跟踪算法自动传播**到后续帧 |
| 场景 | 无人机载 RGB 相机，户外田野 |

**价值：** 唯一同时具备"无人机视角 + 个体身份 ID"的数据集，与 Cattle-counting（纯计数）形成任务层互补。

**两个必须处理的坑：**

1. ⚠️ **不能整批纳入**。46,430 帧来自 34 段视频，帧间高度相关。按 CowCV 2.2 节"按文件序列和子目录分层视觉抽样"的做法，建议**每段视频均匀抽 10–20 帧**，落点约 340–680 帧，与 34 段视频的多样性匹配。
2. ⚠️ **框质量必须审计**。KCF 跟踪传播的框存在漂移风险，尤其牛只相互遮挡或出画时。需抽样人工核验，必要时按 CBVD-5 的处理方式先复核再用。
3. ⚠️ **注意与 AerialCattle2017 同论文的 FriesianCattle2017 的关系**——两者共享论文但数据独立（一为航拍、一为通道俯视），不算同源；但 FriesianCattle2017 与 Cows2021 同源（见 2.6）。

### 2.4 Aerial Pasture — ⚠️ 许可与重复性双待核

| 项 | 内容 |
|---|---|
| 论文 | Shao, W., Kawakami, R., Yoshihashi, R., You, S., Kawase, H., Naemura, T. (2020). *Cattle detection and counting in UAV images based on convolutional neural networks.* Int J Remote Sens 41(1):31-52. DOI 10.1080/01431161.2019.1624858（东京大学/NII） |
| 获取 | ⚠️ 原站 `bird.nae-lab.org/cattle/` **实测无响应**；替代源：Dataset Ninja 镜像（Supervisely 3.28 GB，或原始格式 Dataset1 图 3.17 GB + Dataset2 72.9 MB） |
| 许可 | ⚠️ **CC BY-NC-ND 4.0（禁止演绎）** |
| 规模 | 数据集 1：656 图（晴天 50 m 高，覆盖约 80×60 m）；数据集 2：14 图（不同区域季节）；共 1,948 标注 |
| 标注 | 边界框 + **4 类数据质量元数据**（正常/截断/模糊/遮挡） |
| 亮点 | 用 SfM 三维重建合并多图检测结果，避免重复计数 |

**两个阻塞项：**

1. ⚠️ **许可冲突（最关键）**：CC BY-NC-ND 的 **ND（No Derivatives，禁止演绎）** 条款意味着**不能发布基于它的修改版/转换版**。而 CowCV 的核心交付之一是数据门户与统一标注发布——把原始框转成 YOLO 格式、重命名、重新划分，都可被解释为"演绎作品"。**纳入前必须获得作者书面许可，或仅作为外部评测集引用而不纳入数据门户发布**。
2. ⚠️ **与 Aerial-livestock-dataset 的近重复风险**：两者都是亚洲团队、草地放牧、航拍小目标牛。虽论文团队不同（清华 vs 东大/NII），也未见同源证据，但**视觉场景高度相似**，必须做图像级近重复审计，否则会同时引入两个高度相关的"航拍域"。

**若许可解决，其独特价值**：那套"数据质量元数据"（截断/模糊/遮挡）与 CowCV 强调的元数据记录理念高度契合，可用于分析标注质量对检测指标的影响——这是个现成的实验素材。

### 2.5 CVB（Cattle Video Behaviors）— ⚠️ 抽帧后可用

| 项 | 内容 |
|---|---|
| 论文 | Zia, A., Sharma, R., Arablouei, R., et al. (2023). *CVB: A Video Dataset of Cattle Visual Behaviors.* arXiv:2305.16555（CSIRO） |
| 获取 | ✅ `data.csiro.au/collection/csiro:58916v1`，DOI 10.25919/3g3t-p068 |
| 许可 | CC BY-NC-SA 4.0（署名-非商业-相同方式共享）—— **SA 条款同样影响再分发方式** |
| 规模 | 502 段 15 秒视频 × 450 帧 = **约 225,900 帧** |
| 标注 | 每帧每个牛边界框 + 11 类行为标签，另提供标准 AVA 格式 |
| 场景 | 澳大利亚放牧场，四机位（场地四角 Go-Pro），25 m×25 m，最多 8 头同框 |

**可用但需处理：**

1. ⚠️ 帧量与 AerialCattle2017 同理——225,900 帧绝不能整批纳入。**按视频抽帧**，建议每段抽 5–10 帧（约 2,500–5,000 帧），并保留视频级分组信息以支持"来源感知划分"。
2. ⚠️ 场景与 XGain 高度重叠（都是户外草场高位俯视）。XGain 已纳入 1,657 张，需评估 CVB 加入后"户外草场域"是否过度代表。
3. ✅ 额外收益：行为标签可作为扩展标注保留（符合 2.1 节"行为、身份等信息仍作为扩展标注保留"的定位），支持后续多任务研究。
4. ⚠️ **SA 条款**需与 CowCV 数据门户的许可策略对齐。

### 2.6 FriesianCattle2017 — ❌ 不建议纳入（同源泄漏）

| 项 | 内容 |
|---|---|
| 论文 | Andrew, W., Greatwood, C., Burghardt, T. (2017). ICCVW. DOI 10.1109/ICCVW.2017.336 |
| 规模 | 940 图 / 89 头，室内通道俯视 |
| 采集 | **与 FriesianCattle2015 完全相同**的相机与装置；相机架设在待挤栏与挤奶站之间通道上方 |

**不建议的理由：**

- ⚠️ **与已纳入的 Cows2021 同源同场景**：Cows2021 的 10,402 张图同样来自"待挤栏与挤奶厅之间的走道、4 m 固定垂直俯视、同一牛群"，出自同一 Bristol 团队。FriesianCattle2017 的 940 张几乎是同一视角的早期子集。
- 一旦同时纳入，会构成**实质性的数据泄漏**（同一批牛的同一机位图像出现在训练与评测两侧），并违反纳入原则第 5 条"跨数据集近重复审计"。
- 场景上也无法提供新域：顶视走道域已被 Cows2021（10,402 张）充分代表。
- 论文表 1 已把 OpenCows2020（同团队、整合了 2016/2017 数据）排除，**逻辑上应保持一致**——否则等于换个名字把同源数据放进来。

### 2.7 Cows Frontal Face — ❌ 不适合（框语义不兼容）

| 项 | 内容 |
|---|---|
| 论文 | Ahmed, S.U., Frnda, J., Waqas, M., Khan, M.H. (2024). *Dataset of cattle biometrics through muzzle images.* Data in Brief 53:110125. DOI 10.1016/j.dib.2024.110125 |
| 获取 | ✅ Zenodo 10535934，13.9 GB，CC BY 4.0（许可最宽松） |
| 规模 | 2,893 张 / 459 头；采集时用三台设备拍**正脸/鼻纹** |

**不适合的理由：**

- ⚠️ 标注的是**鼻纹/脸部框**，不是整牛框。按 CowCV 规则需重新绘制整牛 HBB，但这类图像**通常拍摄得很近，牛的身体根本不在画面内** → 无法满足纳入原则第 1 条"可辨认的完整或主要可见牛体目标"。
- 强行纳入会引入一批"只有脸没有身体"的样本，严重污染单类整牛检测的语义。
- 结论：**维持为相关工作引用**，可放入论文的"其他任务类型数据集"讨论，但不进检测基准。

### 2.8 OpenCows2020（复议）— ❌ 维持排除

- 原排除决定正确。它与 Cows2021 **同团队、同牛群、同场景**，且 Cows2021 论文明确其数据整合了 Andrew 此前工作（2016/2017/2019）——OpenCows2020 正是那批工作的汇总。
- **关键推论**：这个"同源"逻辑必须**同步适用于 FriesianCattle2017**（见 2.6），否则两处判断会互相矛盾。
- 建议在论文中把排除理由写明确（现在表 1 只写"仅作为相关工作引用"，未说明是因为**同源重叠**），审稿人容易追问。

### 2.9 CattleEyeView（复议）— ❌ 维持排除

- 三条理由支持维持：
  1. **场景冗余**：顶部俯视通道，与 Cows2021、8-calves、COLO、MooTrack360 同属 G1-a/G1-b 顶视族，该族已有 4 个数据集；
  2. **标注语义混杂**：同时提供"身体框 + 头部框"，头部框不符合整牛语义，纳入前需拆分标注，否则框语义不统一；
  3. **实例密度偏低**：30,703 帧仅 753 个实例（约 0.025 个/帧），说明大量重复帧，有效信息密度低。
- 但如果后续要扩展"多品种"维度，它的 **6 个品种**（安格斯/婆罗门/夏洛莱/抗旱王/海福特/圣格鲁迪斯）是现有数据集中最丰富的——可作为**待议项**保留，需先解决标注拆分问题。

## 四、两个需要你决策的结构性问题

### 4.1 CowCV 的域标签体系缺"无人机航拍"这一档

现有视角标签是：顶部俯视、高位斜俯视、地面侧视、多视角、鱼眼。而本次推荐的 3–4 个候选数据集（80–120 m 无人机、50 m 航拍、四旋翼）**目标尺度比现有所有数据小一个量级**（牛约 87×90 像素，甚至更小）。

建议：在"拍摄视角"维度下**新增"无人机高空航拍"**，或把"尺度"从"目标结构"里独立出来作为单独维度。否则新增的航拍数据只能勉强归入"顶部俯视"，会掩盖真正的域差异——而这恰恰是最能体现跨域泛化难度的域。

### 4.2 航拍域可能过度代表

若 P0+P1 全纳入，航拍类将达约 **5,800+ 张**（Cattle-counting 5,058 + Aerial-livestock 89 + AerialCattle2017 抽帧后的数百），而室内场景（8-calves 900、COLO 1,004）反而偏少。

由于 CowCV 的 14 域定向迁移实验对**域间样本量差异**敏感，建议：
- 要么对航拍大集做**子采样**保持域平衡；
- 要么在论文中显式记录各域样本量差异，并在跨域结论中讨论其影响。
