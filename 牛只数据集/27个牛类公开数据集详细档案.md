## A 组 · Bristol 视频个体识别系（5 个）

英国布里斯托大学 Burghardt 团队出品，是牛只身份识别领域**引用最高、数据最规范**的一支。全部走 University of Bristol 数据仓库（data.bris），许可统一为 **Non-Commercial Government Licence**（仅限非商业用途），是学术界最常被复用的牛只数据集系列。

### A1. FriesianCattle2015 ✅（同域名已验证）

```text
Andrew, W., Hannuna, S., Campbell, N., Burghardt, T. (2016).
Automatic Individual Holstein Friesian Cattle Identification via Selective
Local Coat Pattern Matching in RGB-D Imagery. ICIP 2016, pp. 484-488.
DOI: 10.1109/ICIP.2016.7532404
```

| 字段 | 内容 |
|---|---|
| 下载 | https://data.bris.ac.uk/data/dataset/wurzq71kfm561ljahbwjhx9n3 |
| 规模 | 764 对 RGB-D 图像 / 92 头荷斯坦 | 
| 划分 | 训练 10 头 83 图；测试 40 头 294 图（约 86,000 图像对） |
| 采集 | 挤奶站出口上方 4 m，Kinect RGB-D；深度 512×424@16bit，RGB 1920×1080@30fps |
| 标注 | 图像级（个体 ID） |
| 论文性能 | SVM + ASIFT 局部花纹描述子，识别准确率 **97%** |
| 说明 | 首个公开的 3D 牛只数据集，用距离阈值（2–3.4 m）做背景分割 |

### A2. FriesianCattle2017 ❓

Andrew, W., Greatwood, C., Burghardt, T. (2017).
Visual Localisation and Individual Identification of Holstein Friesian Cattle
via Deep Learning. ICCVW 2017 (VWM Workshop), pp. 2850-2859.
DOI: 10.1109/ICCVW.2017.336
```

| 字段 | 内容 |
|---|---|
| 下载 | https://data.bris.ac.uk/data/dataset/2yizcfbkuv4352pzc32n54371r |
| 规模 | 940 图 / 89 头，室内通道俯视 |
| 采集 | 与 2015 同款相机（池与挤奶厅间通道上方） |
| 标注 | bounding box（每头牛唯一 ID） |
| 方法 | R-CNN 定位 + 个体识别 |

### A3. AerialCattle2017 ❓

| 字段 | 内容 |
|---|---|
| 下载 | https://data.bris.ac.uk/data/dataset/3owflku95bxsx24643cybxu3qh |
| 规模 | 34 段牛群视频（平均 ~20 s）→ **46,340 帧** |
| 采集 | 无人机 + RGB 相机，户外田野 |
| 标注 | 首帧手工标框，后续帧用 **KCF 跟踪**自动裁剪 ROI 再归类 |
| 亮点 | 早期"用跟踪算法降标注成本"的典范；航拍视角个体识别 |

Computers and Electronics in Agriculture 185:106133.
DOI: 10.1016/j.compag.2021.106133 ｜ arXiv:2006.09205
```

| 字段 | 内容 |
|---|---|

### A5. Cows2021 ✅ 实测有效（目前最大牛只识别数据集）

```text
Gao, J., Burghardt, T., Andrew, W., Dowsey, A.W., Campbell, N.W. (2021).
Towards Self-Supervision for Video Identification of Individual Holstein-Friesian
Cattle: The Cows2021 Dataset. arXiv:2105.01938
```

| 字段 | 内容 |
|---|---|

| 结构 | ① Detection_and_localisation（train/val/test + annotations）② Identification（186 个 ID 目录）③ Train Videos ④ Weights（作者已训练权重） |
| 标注 | **带朝向角的有向 bounding box**（cx, cy, w, h, θ），共 13,784 实例 |

| 论文性能 | 自监督对比学习 + GMM 聚类：Top-1 **57.0%**、Top-4 76.9%、ARI 0.53 |
| 配套代码 | https://github.com/Wormgit/Cows2021 |
| 备注 | 明确标注"视频级自监督信号"可减少人工标注，是做**无监督/半监督域适应**的好素材 |

## 给池化实验的三条实操建议

1. **首选可直接批量下载的 9 个**（上表 ✅ 组）。其中 OpenCows2020 + Cows2021 + CattleEyeView + CVB 都带**多视角/多时段/多品种**变化，是研究域差异对池化影响的理想组合。
2. **红外池化候选只有 3 个**（HolsteinCowRecognition、HolsteinCattle、Dairy Cow），其中 Dairy Cow 链接已失效——如果你要做红外多源池化，**只能靠自己的 CMBN/HCRD 补齐**，这恰好是该方向的数据稀缺性证据。
3. **许可有雷**：Bristol 系列是 Non-Commercial Government Licence、CVB 是 CC BY-NC-SA 4.0、Aerial Pasture 是 CC BY-NC-ND 4.0（**禁演绎**，二次分发受限），发表时要注意合规；BeefCattleMuzzle、Cows Frontal Face、CattleEyeView 是 CC BY 4.0 最宽松。
