# 视觉语言模型零样本检测与困难子集分析计划

> 编写日期：2026-10-19  
> 对应论文：CowCV：面向牛只检测的数据资源标准化与跨数据集有向迁移基准  
> 文档性质：待执行的研究与实验计划，不代表已经获得实验结果。  
> 当前范围：增加零样本检测参照、构建参考模型困难子集、开展场景属性与跨模型验证；本计划不修改论文正文，不启动训练或推理任务。

## 1. 研究定位与预期贡献

CowCV 当前工作的主线是多源牛只数据资源、统一检测表示与跨数据集评测。新增视觉语言模型内容，宜围绕“现有通用模型能否直接处理这些视觉域，以及哪些样本持续困难”展开，与已有监督检测和有向迁移实验形成互补。

本计划提出三个研究问题：

1. **零样本检测能力：** 未经 CowCV 任务微调的文本条件检测器，在14个冻结目标域上的检测表现如何？
2. **困难子集可复核性：** 能否依据预测框与真实框的匹配结果，得到规则明确、可重建的困难候选清单？
3. **困难的跨模型一致性与场景关联：** 由一个参考模型筛出的候选，对独立模型是否同样困难？困难是否与小目标、遮挡、鱼眼、视角和低照度等属性相关？

预期贡献落在“统一评测协议、困难子集资源与有证据的失败分析”，不预先声称提出新检测架构，也不把新增一个模型本身当作主要创新。

拟在完成实验后增加论文第4.6节：**视觉语言模型零样本检测与困难子集分析**。

## 2. 实验边界与术语

### 2.1 两类视觉语言模型的职责

| 类型          | 拟用模型                      | 本计划中的职责        | 输出                |
| ----------- | ------------------------- | -------------- | ----------------- |
| 文本条件开放词汇检测器 | Grounding DINO-T          | 主零样本参照与困难候选筛选器 | 检测框、文本相关分数        |
| 独立开放词汇检测器   | OWLv2                     | 验证困难子集的跨模型表现   | 检测框、分数            |
| 通用生成式视觉语言模型 | Qwen3-VL-8B-Instruct      | 辅助提取场景属性       | 结构化属性、证据描述、无法判断标记 |
| 已有监督检测器     | 原始 YOLO11m、必要的域内或 LODO 模型 | 提供不同训练条件下的补充对照 | 检测框、分数            |

Grounding DINO 和 OWLv2 的文本条件检测能力分别依据官方实现与模型资料确认。[R1][R2] Qwen3-VL 属于图像与文本输入、文本输出的模型，本计划拟用其辅助场景标记；实际标签质量需要人工验证。[R3]

### 2.2 “零样本”的限定

本计划的主口径为：**不使用 CowCV 目标域标签进行任务微调、提示词搜索、阈值优化或模型选择，直接使用预训练权重和事先固定的推理规则。**

- “未经 CowCV 微调”不等于“预训练阶段从未见过牛、目标数据集或近重复图片”。
- 按具体 checkpoint 登记预训练来源。官方 Grounding DINO-T 与 Grounding DINO-B 的训练数据列表不同，不能互相代用其来源声明。[R1]
- 对 COCO、Open Images 和其他网络来源域，单列预训练来源重叠风险；无法核查的项目记为“未知”。
- OWLv2 模型卡中部分训练数据描述注明仍待更新，不能据此断言该具体权重完全不含某目标数据来源。[R2]
- 如果后续使用 CowCV 验证标签调整提示词或阈值，必须另列为“有目标域校准的补充实验”，不混入上述主结果。

## 3. 数据准备与冻结视图

### 3.1 主评测范围

以现有稿件的14个基准数据集为候选范围：

`Cows2021`、`8-calves`、`COLO`、`MooTrack360`、`XGain`、`Dairy Cow`、`CID`、`HCRD`、`NWAFU Cattle Dataset`、`animals_10`、`CImage`、`COCO cow subset`、`Google Open Images cow subset`、`CBPD_ODD`。

**第一轮仅跑冻结评测图像，不默认扫描全部31,373张图像。** 全量图像的属性标记属于后续资源扩展，不能混入主评测分母。

主分析优先沿用现有14×14矩阵与原始 YOLO11m 参照的目标视图，便于同目标比较。以执行前重新核对的清单为准，不直接采用旧表中的数量。

当前稿件明确存在以下比较边界：

- 第4.5.1节与第4.5.2节 LODO 使用的目标视图不完全相同。
- Dairy Cow 的名义 `test` 别名在稿件记录中仍指向 `val`，不能因此称为独立测试集。
- Cows2021 等数据包含躯干框或特殊转换语义，低定位分数不能自动解释为识别能力不足。

以上属于当前稿件记录，不是本计划新增的远程核验结果。执行时需复核。

### 3.2 冻结清单

每张图至少登记：

| 字段                                      | 用途                      |
| --------------------------------------- | ----------------------- |
| `image_id`、`dataset_id`、`relative_path` | 唯一标识与资源定位               |
| `image_sha256`、`annotation_sha256`      | 确认图像与标签版本               |
| `view_id`、`split_status`                | 区分冻结视图、独立 test 与验证视图    |
| `width`、`height`、`num_gt`               | 坐标还原、尺度与密度分析            |
| `source_group_id`                       | 视频、牛只、相机或采集来源分组；未知时明确标记 |
| `annotation_policy`                     | 整牛、躯干、可见范围或推断范围等标注语义    |
| `quality_flag`、`provenance_note`        | 标注疑点、重复与来源证据            |

一个数据域内，所有参与比较的模型使用完全相同的图像、真实框、类别映射及忽略规则。某模型推理失败时，单列失败数与覆盖率，不通过删图悄悄改变比较集合。正式主表以该视图全部图像完成有效推理为前提；未补齐的结果标为未完成，临时共同完成集的结果必须另标分母和视图身份，不能冒充完整集合。

### 3.3 标注问题的处理

先核对格式、坐标、漏标疑点和框语义，再区分视觉困难与标注问题：

- 原始视图保留，以记录当前资源条件下的表现。
- 需要修订标注时，创建独立版本与修订记录，不能直接覆盖旧标注。
- 一旦在修订视图上做正式比较，全部相关模型需在该视图上重新计算指标和困难清单。
- 从困难图中发现的疑似标注错误，不能未经审核就删除；普通图也要抽查，避免只检查低分样本。

## 4. 模型与推理协议

### 4.1 首轮模型配置

| 优先级  | 模型或权重                                                                         | 角色            |
| ---- | ----------------------------------------------------------------------------- | ------------- |
| 必做   | Grounding DINO-T，`GroundingDINO_SwinT_OGC.py` + `groundingdino_swint_ogc.pth` | 主零样本参照、唯一主筛选器 |
| 必做   | `google/owlv2-base-patch16-ensemble`                                          | 独立零样本验证器      |
| 必做   | 原始 `yolo11m.pt`                                                               | 现有通用预训练参照     |
| 第二阶段 | `Qwen/Qwen3-VL-8B-Instruct`                                                   | 场景属性辅助标记      |
| 按需补充 | 已有域内 YOLO11m 或 LODO checkpoint                                                | 监督训练或跨域泛化对照   |

上述检测模型与生成模型的名称、权重入口依据官方资料列出，执行时还需固定下载 revision、文件 SHA-256 和代码 commit。[R1][R2][R3]

不同模型使用各自固定的官方预处理，并记录输入尺寸、缩放、精度和后处理。其比较表示所报告配置的表现，不直接解释为控制了所有计算条件的架构优劣。

### 4.2 文本提示词

- Grounding DINO 主提示词固定为 `cow .`，使用对应词元的分数映射到唯一类别 `cow`。
- OWLv2 主提示词固定为 `a photo of a cow`，唯一查询类别映射为 `cow`。
- 两个模型的完整提示词、词元映射和文本处理版本均写入配置。
- `cattle`、`calf` 等词汇变体可作为事先列出的敏感性实验，必须完整报告，不能按测试域挑选最高分版本。
- 主实验不做多提示词集成、不按图像内容自动修改检测提示词。

### 4.3 区分 AP 候选收集与 F1 工作点

AP 基于分数排序及多工作点评估；F1 则对应一个固定工作点。COCO 评估器提供多 IoU 阈值与最大检测数量等配置，需保存实际参数。[R4]

本计划固定如下规则：

| 项目 | 拟定设置 |
| --- | --- |
| 类别 | 单类别 `cow` |
| AP IoU 阈值 | 0.50至0.95，步长0.05 |
| AP 候选收集 | 尽量保留未施加高展示阈值的原始候选；如需下限，统一记录为0.001 |
| 主评测每图检测上限 | 300；指标显式标为 `AP50:95@maxDets300` |
| 标准设置补充 | 另报 `maxDets100` 结果，不将300上限结果冒充标准100上限结果 |
| 困难筛选工作阈值 | Grounding DINO 的 `cow` 分数≥0.25，事先固定 |
| 图像级匹配 IoU | ≥0.5 |
| 其他模型固定工作点补充 | 可报分数≥0.25的 P/R/F1；不声称不同模型分数已校准 |
| 主困难阈值 | 图像级 F1严格低于0.6 |

Grounding DINO 官方演示的展示阈值不能直接充当 AP 收集下限；文本解码阈值也不能误当成唯一类别 `cow` 的额外筛除规则。[R1] 实现时需核对候选数量、实际最低分数与标签映射。

300上限是本计划针对密集牛群预先提出的配置，不是所有模型的官方默认。评估和摘要程序都需核对实际使用的上限，不能只修改参数却沿用写死100的摘要逻辑。仍需报告每图真实目标数超过上限的比例、候选被截断的比例和模型自身候选数量限制；相关限制可能影响密集场景结果。

首轮保留各模型明确记录的原生后处理；是否使用 NMS、阈值、排序及截断顺序均固化。若另加统一 NMS，须列为独立补充配置。

### 4.4 运行记录

记录 GPU、驱动、CUDA、Python、PyTorch、推理库版本、checkpoint、提示词、精度、batch、输入大小和配置哈希。初始使用 batch=1，先测显存与耗时，再决定批处理规模。

不根据旧记录假定当前服务器、数据路径或 GPU 型号。服务器和环境核对属于正式执行阶段，本次计划未进行连接测试。

## 5. 检测指标与数据域汇总

每个模型、每个数据域至少报告：

- 图像数、真实实例数、有效来源簇数及推理覆盖率。
- AP50、AP50:95，并在表头注明 `maxDets`。
- 固定工作点的 Precision、Recall、F1及其分数阈值。
- 如做效率分析，另报输入配置、端到端单图耗时和峰值显存。

单类别任务中可沿用稿件的 mAP 术语，但正文需说明其与唯一类别 AP 的关系。图像级困难评分不称为“单张图 mAP”。

总体主汇总采用数据域等权宏平均：

$$
\overline{AP}^{macro}=\frac{1}{K}\sum_{d=1}^{K}AP_d.
$$

同时报告中位数、最差目标域、有效域数和缺失项。每域先计算完整评测集 AP，再做宏平均，不能用图像级 F1平均值代替 AP。

来源信息充分时按视频或采集来源进行 cluster bootstrap；未知来源只能按图像重采样，并说明其不能排除帧间相关性。无训练实验不需要新增训练随机种子结果。

## 6. 困难候选的操作性定义

### 6.1 主定义：H60

固定主筛选器为 Grounding DINO-T，使用第4节的提示词、工作阈值与上限。以下 \(N_i^{GT}\) 指参与评分的非忽略真实牛只数。对每张 \(N_i^{GT}>0\) 的图像：

1. 将有效预测框按分数降序排列，同分时使用稳定的候选索引排序。
2. 对每个预测框，在尚未匹配的有效真实框中选择 IoU 最大者；IoU≥0.5时记为 TP。
3. 未匹配预测记为 FP，未匹配真实框记为 FN；存在 crowd/ignore 标记时固定并记录其处理政策。
4. 计算图像级 F1：

$$
F1_i=\frac{2TP_i}{2TP_i+FP_i+FN_i}.
$$

主困难候选与其余图像定义为：

$$
H_{60}=\{i:N_i^{GT}>0,\ F1_i<0.6\},
$$

$$
C_{60}=\{i:N_i^{GT}>0,\ F1_i\geq0.6\}.
$$

`C60` 称为“其余图像”或“对照集合”，不直接称为普遍容易的图像。`F1=0.6` 归入 `C60`。

该定义描述**参考模型在指定协议下的困难**。0.6是本研究预先规定的操作性阈值，不是已有通用难度标准，也不是模型预测正确的概率。

### 6.2 边界情况与解释限制

- 有真实牛只但无有效预测：`F1=0`，纳入 H60。
- 无真实牛只的负样本：不纳入上述 H60 分母，另报误检图像比例与每图误检数。
- 图像或标签无法读取：记录为评测失败，不按 `F1=0` 混入视觉困难。
- 单牛或少目标图像的 F1取值较离散；不能将不同目标数图像的分数差完全解释为难度差。
- 部分困难可能来自框语义或定位要求。同步保留 TP/FP/FN、匹配 IoU和标注语义，区分漏检、误检与定位不一致。

模型置信度或文本相似度低于0.6不直接等于困难。现代神经网络的置信度不必天然校准；一般校准研究也不能代替对本项目具体模型的校准验证。[R5]

### 6.3 困难占比

数据域内困难占比定义为：

$$
h_d=\frac{|H_{60,d}|}{N_d^{positive}}.
$$

其中 \(N_d^{positive}\) 为完成有效困难评分、且至少有一个非忽略真实牛只的图像数；同时报告它占冻结正样本集合的覆盖率，未完成视图不发布完整集合的困难占比。

总体同时报告数据域等权宏平均困难占比和全部有效正样本的图像加权困难占比，注明二者分母，不互相代替。保留每域的连续 F1分布，避免只提供一个二值标签。

### 6.4 预先规定的敏感性分析

- 困难阈值：0.5、0.6、0.7；主结果始终为0.6。
- 参考模型工作分数：0.15、0.25、0.35；主结果始终为0.25。
- 报告困难占比、集合交并比以及主要属性关联是否变化，不从组合中挑出最符合预期的一项。
- 额外设置先登记为探索性分析，不能事后替换主协议。

以上多数统计可从已保存的低阈值预测中重算，无需重复 GPU 推理；若原预测已被高阈值或候选上限截断，则不能假装可以完整重建。

## 7. 跨模型验证与筛选偏差控制

### 7.1 固定子集后再比较

以 Grounding DINO-T 的主结果一次性生成并冻结 H60/C60 清单，再评估 OWLv2 和已有 YOLO参照。独立验证器不参与主困难清单的生成，也不根据验证器低分重筛主子集。

分别在完整集合、H60、C60上重新计算每个模型的检测 AP，并报告：

$$
\Delta AP_m=AP_m(C_{60})-AP_m(H_{60}).
$$

其中两个子集的 AP分别由其全部预测重新计算，不能把单图 F1均值代入。

Grounding DINO 在自身筛出的 H60上低分属于筛选规则带来的预期现象，不能单独证明困难子集具有跨模型价值。更有解释力的结果来自未参与筛选的 OWLv2 与监督检测器。

### 7.2 控制子集组成差异

H60/C60可能具有不同的数据域、目标数量和尺度组成。至少同时做以下分析：

1. 按数据域分别比较，再对共同有有效子集的域做宏平均，并报告有效域数。
2. 按真实目标数与目标尺度分层，观察困难差异是否只来自密集图像或小目标比例。
3. 小样本子集报告图像、实例与来源簇数；任一侧为空时，差值记为 `N/A`。
4. 不把整个14域拼接后的差值单独解释为跨模型普遍困难。

宏观场景属性之间可能共同变化；这部分结果属于关联分析，不作为某个因素导致掉点的因果证明。

### 7.3 共识困难作为补充

可在主分析完成后描述多个模型共同失败的交集，但必须标为“参与模型定义的共识困难”。参与定义的模型不能同时被当成独立验证证据。

首轮不把共识交集替换为主 H60，也不为得到更低分的子集不断增加筛选条件。

## 8. 场景属性与 VLM辅助标记

### 8.1 按证据来源分配属性

| 属性 | 主要获取方式 | 说明 |
| --- | --- | --- |
| 目标数量、相对框面积、框尺度分布 | 从真实标注计算 | 保存连续数值；密度分组另行预先固定 |
| 小目标比例 | 依据真实框计算 | 主分析保留归一化尺度；若使用像素阈值，注明原图或缩放坐标 |
| 室内、半开放、户外、混合背景 | VLM辅助，人工核验 | 不根据数据集名称整域赋值 |
| 俯视、斜俯视、侧视、视角不确定 | VLM辅助，人工核验 | 多标签或保留不确定状态 |
| 鱼眼特征、低照度、明显模糊、目标遮挡 | VLM辅助，人工核验 | 不将语言判断冒充精确物理测量 |
| RGB、红外、相机型号、牛只身份、来源关系 | 原始资料与元数据 | 无证据时记未知，不凭黑白图像推断红外 |

相对目标面积可定义为真实框面积除以图像面积。分位数或其他分组边界在开发阶段固定，正式结果同时提供连续分布，避免只靠任意“大小”阈值。

### 8.2 VLM输入与提示

使用固定的 Qwen3-VL-8B-Instruct 权重、图像处理、提示词和确定性生成设置；具体显存与输入像素预算由试跑实测。[R3]

主标记只输入原始图像，不输入筛选模型得分、H60身份或模型预测框，减少属性标记受失败结果暗示的影响。需要局部裁剪复核时，使用统一规则并单独记录。

提示词草案：

```text
请仅依据图像中可见的信息标记场景属性，不要推断相机型号、红外模态、
数据集来源或精确遮挡百分比。无法判断时输出 unknown。

输出 JSON，包含：
environment: indoor / semi_open / outdoor / mixed / unknown
viewpoint: top / oblique / side / mixed / unknown
fisheye_visible: yes / no / unknown
low_light_visible: yes / no / unknown
obvious_blur: yes / no / unknown
cow_occlusion_visible: yes / no / unknown
evidence: 对上述判断给出简短的可见依据
```

标签是拟定方案，需先在不属于正式评测的开发图像上试标与修订；标签字典和提示词冻结后再批量标记。

### 8.3 人工质量验证

- 第一批建议抽查约200张，按数据域及 H60/C60 分层随机抽取；小数据域可全部抽查，保存抽样概率。
- 人工标记者尽量不看模型名称、分数和困难身份，先独立判定图像属性，再对照 VLM输出。
- 其中一部分由第二人独立标记并记录分歧；样本少或类别极不平衡时，不只报告总体一致率。
- 按属性报告混淆情况、未知率和错误案例。分层过采样后的总体估计需按抽样概率加权，不能直接当成全体标签准确率。
- 某属性可靠性不足时，改为人工审核字段或探索性标签；不能继续作为未经验证的正式定量结论。
- 不要求所有 H60都具有同一种场景原因，不将 VLM的文字解释直接称为失败的因果解释。

正式首轮优先覆盖整个冻结评测集合的简短结构化标记；若资源不足，只做上述概率抽样并报告估计范围，不把只标记困难图得到的属性频率用于困难/对照比较。

## 10. 现有结果复用规则与成本估计

### 10.1 可直接复用的条件

旧结果必须同时满足：

1. 图像集合、标签文件、类别与 ignore 政策相同。
2. checkpoint、输入处理和推理配置明确。
3. 有逐图框与分数，能重新计算 AP及 H60/C60子集指标。
4. 预测没有因过高分数阈值被不可逆截断；候选上限符合本轮配置。

只有汇总 mAP表格时，无法据此重建困难图像清单或子集 AP，需重新推理。已有 LODO模型若使用另一套视图，只能在本轮视图重新推理后参与配对比较；同时说明新视图的训练、验证和选模隔离是否仍然成立。

### 10.2 先实测再排期

定义冻结集合总图像数为 \(N\)，模型 \(m\) 的实测平均端到端耗时为 \(t_m\)，则粗略推理成本为：

$$
T_{\mathrm{det}}\approx N\sum_m t_m.
$$

属性标记成本按实际标记图像数另算。试跑至少覆盖普通图、密集图和高分辨率图，分别记录耗时与显存；正式排期再加入加载、读盘、保存和重试开销。本计划不承诺尚未测量的小时数。

计算资源不足时按以下顺序收缩：

1. 保留 Grounding DINO、原始 YOLO参照和可复核的 H60清单。
2. 独立 OWLv2验证作为形成“跨模型困难”结论的必要补充；未完成前只称参考模型困难。
3. VLM属性标记先做概率抽样与人工验证，再决定是否全量。
4. 多提示词、大模型权重和更多监督模型放入后续扩展。

## 13. 论文写作安排与结论边界

拟新增结构：

```text
4.6 视觉语言模型零样本检测与困难子集分析
    4.6.1 文本条件检测模型与统一评测协议
    4.6.2 十四域零样本检测结果
    4.6.3 参考模型困难子集的定义与分布
    4.6.4 独立模型验证及场景属性分析
```

完成实验后，再视结果更新相关工作、实验设置、贡献和局限。摘要仅加入有清晰证据且足以支撑主线的发现。

可争取的贡献表述为：

> 在统一冻结评测视图上建立文本条件牛只检测参照，发布规则可复现的参考模型困难子集与经审核的场景属性，分析不同检测范式的失败重合与场景差异。

上述是预期写作方向，实际结论取决于结果：

- 只有筛选器下降：只能确认该参考模型的困难子集。
- 独立模型在多数可比较域也下降：可描述参与验证模型间的困难迁移，并报告例外。
- 主要差异来自框语义或标注问题：优先报告资源标准化与评测风险。
- VLM属性质量不足：保留人工核验结果，不用未经验证的自动标签支撑定量结论。
- 小样本或来源信息不足：限定为当前集合的描述性证据。

不预写“VLM显著优于YOLO”“60%是统一困难标准”“遮挡导致所有掉点”或“困难子集对所有模型都困难”等结论。
