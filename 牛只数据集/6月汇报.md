## CowCV Benchmark Plan（草案）

> **这里和刘洋原计划做融合数据集与单数据集测试**
>
> （本项测试旨在评估**多源域混合训练对目标检测模型跨域泛化（Cross-Domain Generalization）与域内泛化（In-Domain Generalization）能力的影响**。期望结果为融合数据集权重在原数据集上表现更好，实际实验发现无法完成。从计算机视觉与迁移学习的理论及过往文献来看，**在绝大多数情况下，$P_E$ 在各域测试集上的 mAP 不会高于专用权重 $P_A, P_B, P_C, P_D$。**
>
> 实验构建了一个由四个具有不同域特征（Domain Characteristics）的目标检测数据集（记为 $A, B, C, D$）组成的基准测试平台。每个独立数据集的样本划分均保持一致，即包含 $n$ 张训练图像、$m$ 张验证图像和 $k$ 张测试图像。
>
> 整个评估流程分为两个阶段：
>
> 1. **域内基准训练（In-Domain Baseline Training）**：模型分别在 $A, B, C, D$ 四个原始训练集上进行独立训练，收敛后收录对应领域的专用权重，记为 $P_A, P_B, P_C, P_D$。
> 2. **多源域混合训练（Multi-Source Mixed Training）**：从 $A, B, C, D$ 的训练集与验证集中分别等比例（$1/4$）随机抽样，重组为一个规模与单一源域完全一致（训练集规模为 $n$，验证集规模为 $m$）的混合数据集 $E$。模型在 $E$ 上训练得到泛化权重 $P_E$。
>
> 最终，实验通过对比 $P_E$ 与各专用权重（$P_A \sim P_D$）在对应独立测试集（$A_{test}, B_{test}, C_{test}, D_{test}$）上的平均精度均值（mAP），来量化多源域联合泛化收益。
>

### 2. 评测协议

- **训练/验证/测试划分**: 每个数据集 70%/15%/15%（MooTrack360 已有原生划分 1200/150/150）
- **跨数据集泛化**: Train on A, test on B/C/D — 评测跨场景泛化能力
- **全量合并训练**: 4数据集合并后 shuffle 划分
- **评价指标**:
  - 主指标: **mAP@50, mAP@50:95**
  - 辅助: Precision, Recall, F1-score
  - 效率: 推理时间 (ms), FPS, 模型参数量, FLOPs

1. **单数据集模型泛化差**：各单数据集模型在"自测"上表现优异（对角线 mAP@50 0.927–0.988），但跨域泛化急剧下降。8-Calves 模型在 MooTrack360 上仅 0.1052，说明室内犊牛特征无法迁移到鱼眼场景。

2. **Merged 模型全面碾压**：合并训练模型在**所有 4 个测试集上均接近或超越**对应的单数据集专精模型，平均 mAP@50 达 **0.923**，比最强单模型平均值（0.623）高出 **48.1%**。

3. **mAP@50-95 同样显著**：Merged 平均 0.584，远超单模型最高平均 0.336，说明合并训练不仅提升检测精度，定位精度也大幅改善。

4. **多样性训练的价值**：仅 600 张混合训练图片（每个场景 150 张）即可获得远超 600 张单一场景训练的泛化性能，验证了 **"数据多样性 > 数据同质性"** 的假设。

### 关键教训

- XGain 必须使用 `labels_unified/`（class 0），不能使用 `labels/`（含 0/1/2 行为标签），否则训练崩溃
- MooTrack360 bbox 密集（39,697 instances/600 张），训练和验证速度显著慢于其他数据集
- 国内服务器访问 GitHub 极慢，需提前缓存预训练权重；`amp=False` 可避免额外下载 `yolo26n.pt`
- batch=128 会 OOM（24GB），自动降为 64；未来可用 batch=64 避免降级开销

## 附录

### 目标检测器的分布外（Out-of-Distribution, OOD）泛化

目标检测器的**分布外（Out-of-Distribution, OOD）泛化能力**，是指模型在**测试数据的统计分布与训练数据显著不同**的情况下，依然能够保持准确检测和定位目标的能力。

简单来说，就是模型不仅要“记住”训练集里的样子，还要在面对**从未见过或差异巨大**的新场景时，不发生性能崩溃。

 **1. 什么是“分布偏移” (Distribution Shift)**

在目标检测中，OOD通常由以下几种偏移引起：

- **域偏移：** 训练集是白天/晴天/合成数据，测试集变成夜晚/雨天/真实数据。
- **视角/尺度偏移：** 训练多为平视标准图，测试出现极端俯拍、鱼眼镜头或极小/极大目标。
- **背景/上下文偏移：** 物体出现在训练集中未曾关联的背景中（例如：牛出现在海滩上，而非草地上）。
- **风格/渲染偏移：** 从照片到素描、红外图像或不同相机传感器的成像差异。

 **2. OOD泛化 vs. 传统泛化**

表格



| 特性         | 传统泛化 (In-Distribution) | OOD 泛化 (Out-of-Distribution)                        |
| :----------- | :------------------------- | :---------------------------------------------------- |
| **数据假设** | 测试集与训练集独立同分布   | 测试集分布 Ptest≠Ptrain*P**t**es**t*\\=*P**t**r**ain* |
| **评估指标** | mAP (在COCO等标准集上)     | OOD-mAP, 性能衰减率 ( ΔΔ mAP)                         |
| **核心挑战** | 过拟合、样本不足           | 虚假相关性、特征纠缠、长尾分布                        |
| **典型表现** | 性能稳定                   | 性能急剧下降，甚至完全失效                            |

 **3. 提升OOD泛化的主流思路**

结合 **COUNTS (CVPR 2025)** 基准，当前学术界主要通过以下方式研究和提升该能力：

- **数据层面：** 构建大规模、多领域的OOD基准（如COUNTS），使用混合域训练或数据增强。
- **模型层面：** 采用领域自适应、解耦表征学习、因果推断来消除虚假相关。
- **多模态辅助：** 利用视觉-语言大模型的开放词汇能力和常识知识，作为强先验来弥补纯视觉模型在未知域中的认知盲区。





### 多源域混合训练对目标检测模型跨域泛化（Cross-Domain Generalization）与域内泛化（In-Domain Generalization）

#### 1. 域内样本密度的稀释（Data Dilution）

尽管数据集 $E$ 的总样本量与原始数据集相同（均为 $n$），但对于任意特定域（如域 $A$）而言，其在 $E$ 中的有效训练样本量从 $n$ 锐减到了 $n/4$。目标检测作为一种对特征空间密度敏感的任务，样本量的减少会直接导致模型对该特定域特有分布（如同质背景、特定光照、目标尺寸分布等）的拟合精度下降。因此，在域内测试时，$P_E$ 极难战胜拥有 4 倍本域数据量滋养的 $P_A$。

#### 2. 表征能力的权衡与域冲突（Domain Conflict）

当模型（$P_E$）试图在有限的参数容量内同时兼容 $A, B, C, D$ 四个不同分布的域时，会引发**负迁移（Negative Transfer）\**或\**域梯度冲突（Domain Gradient Conflict）**。模型必须舍弃部分特定域的特有特征（Task-Specific Features），转而学习跨域的通用特征（Domain-Invariant Features）。这种“平庸化”的表征虽然提升了泛化鲁棒性，但却牺牲了在特定单一域上的极致性能（即上限表现）。

#### 3. 唯一的例外情况：强正迁移与正则化收益

只有在满足以下极端假设时，$P_E$ 的 mAP 才**有可能**微幅超越个别专用权重：

- **严重过拟合**：原始数据集（如 $A$）样本量 $n$ 极小且噪声极高，$P_A$ 发生了严重过拟合。而 $E$ 中引入的其他域数据起到了强烈的数据增强和正则化（Regularization）作用，抑制了过拟合。
- **数据互补性**：四个域之间存在极强的语义互补性（例如 $A$ 全是夜间汽车，$B$ 全是白天汽车），联合训练帮助模型补齐了单一域无法学到的完整特征链条。

### 结论综述

综上所述，该测试本质上是在探究“泛化性”与“专一性”的权衡（Trade-off）**。学术界普遍预期：权重 $P_E$ 将展现出优异的**跨域鲁棒性（即 $P_E$ 在未见域上的表现会远好于 $P_A$ 在未见域的表现），但在具体的域内测试（In-Domain Evaluation）中，由于样本量缩减与域间冲突，$P_E$ 的 mAP 通常会**略低于或等同于**各域全量数据训练出的专用权重。
