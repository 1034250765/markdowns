> 按身份识别、检测计数、行为分析、体尺体重等任务整理 100 个已判定可收录条目；每处明细只说明采集内容和标注与当前类别的联系。

## 范围与口径

- **收录范围**：沿用原报告判定为 ✅ 可收录（94 条）与 ⚠️ 有条件收录（6 条）的条目，共 **100 条**；34 条 ❌ 不可收录未列入本分类。
- **信息来源**：[134 个数据集的可收录情况报告](134个数据集的可收录情况报告.md)中的「采集视角 / 设备」与「标注类型」。
- **分类依据**：采集内容与任务监督的联系；保留既有分类范围，但在条目内区分直接标签、论文处理流程与仅有关联的候选数据。
- **多标签**：一条数据集常跨多类，因此各类条数相加为 141，不等于 100；同一编号会在多个章节重复出现。
- **条目格式**：编号｜名称｜判定｜本类别相关的数据形态，下挂**采集**与**标注**两条完整说明。采集只保留与本任务相关的对象、视角、模态及场景；标注说明监督对象、标签粒度、格式与必要限制。
- **⚠️ 的 6 条**：C021、C035、C038、C042、C043、C076，需登录 / 申请 / 机构账号 / 网盘提取码。

**哪些类别的影像不是整牛画面？** 可结合采集对象与实际发布内容作如下区分：

- **主要拍摄其他对象或局部区域**：**肉质 · 胴体品质**拍摄肉块或屠宰后胴体；**放牧 · 牧场遥感**主要提供草场植被的多光谱影像；**挤奶 / 乳头视觉**拍摄乳房、乳头区域的视频，均不是活体整牛外观影像。
- **局部影像占重要部分**：**个体身份识别 / ReID**包含鼻纹、牛脸、眼底和牛背躯干裁剪图，也有较大范围的牛体影像；**部位 / 局部检测**包含鼻部、牛脸和耳标裁剪图，但 C072 的耳标检测子集也提供牛群场景图，不能把这一类全部视为局部特写。
- **整牛、局部和专门检查影像混合**：**疾病 · 健康诊断**包含眼底（C002）、乳腺超声（C079）及皮肤 / 病灶特写；**姿态估计 / 关键点**中的 C041 是牛脸特写；**发情 · 繁殖行为**中的 C105 是人工制作 / 修改的发情斑块图。**多物种通用动物**中也混有牛头、头颈局部及其他物种，均需按条目筛选。
- **部分数据只关注牛体局部几何**：**体况评分 BCS**较多使用背部、后躯的深度形状或 DGE 处理图；**体尺 · 体重测量**中的 C110 也以牛背部 3D 帧为主。**三维重建 · RGB-D**既有单一顶部表面，也有多视角牛体数据，并可能同时提供彩色图、深度图和点云。


## 二、分类明细

### 1. 个体身份识别 / ReID（27 条）

> 个体身份识别回答「这头牛是谁」，利用鼻纹、牛脸、眼底血管或牛背花斑等特征区分不同牛只；重识别（ReID）更关注不同时间、视角或相机中的影像是否属于同一个体。输入可以是局部照片、整牛图像或视频片段，核心标注是牛只身份 ID。它为按个体关联行为、测量和长期观察记录提供基础，主要难点是外观相似、遮挡及跨时间变化。

**鼻纹 / 鼻部生物特征**（7 条）

- **C004**｜[Cattle muzzle biometric dataset (Shojaeipour et al., 2021)](#c004cattle-muzzle-biometric-dataset-shojaeipour-et-al-2021)｜✅｜高分辨率 RGB 图像
    - 采集：在保定条件下从正前方近距离拍摄牛脸，焦点位于鼻部，供鼻纹生物特征识别使用。
    - 标注：鼻部框用于定位与裁剪，裁剪图对应 300 个牛只身份类别，身份标签是本类任务的监督。

- **C008**｜[Beef Cattle Muzzle Image Dataset (Li et al., 2022a)](#c008beef-cattle-muzzle-image-dataset-li-et-al-2022a)｜✅｜RGB 图像（鼻纹）
    - 采集：在自然光下从围栏外以不同距离、角度拍摄自由活动牛只，再形成鼻部裁剪图，保留非受控拍摄变化。
    - 标注：鼻纹图对应 268 个牛只身份类别，原始采集时以耳标核对身份。

- **C015**｜[Cattle Muzzle Pattern Dataset 300 (Pathak & Prakash, 2025)](#c015cattle-muzzle-pattern-dataset-300-pathak--prakash-2025)｜✅｜照片（脸 / 鼻纹）
    - 采集：沿用 C004 的保定条件下正面牛脸 / 鼻部拍摄，并将原图重新组织为身份识别数据。
    - 标注：目录编码 300 个牛只身份，提供 train / val / test 划分，三组覆盖相同身份类别。

- **C016**｜[CMPD268 (Pathak & Prakash, 2025)](#c016cmpd268-pathak--prakash-2025)｜✅｜鼻纹图像
    - 采集：沿用 C008 在围栏外拍摄自由活动牛只形成的鼻纹图，仅调整目录组织与数据划分。
    - 标注：`cattle_XXXX` 目录编码 268 个身份，train / val / test 均覆盖这 268 类。

- **C017**｜[CMPD568 (Pathak & Prakash, 2025)](#c017cmpd568-pathak--prakash-2025)｜✅｜RGB 鼻部图像（两套来源合并）
    - 采集：合并 C004 的保定正面拍摄与 C008 的户外围栏外拍摄，两种采集条件共同构成鼻纹识别输入。
    - 标注：共 568 个目录级身份，300 类使用数字编号、268 类使用 `cattle_XXXX`，附 train / val / test 划分。

- **C045**｜[Cattle Muzzle Image Dataset（附表署名 Kimani et al., 2023）](#c045cattle-muzzle-image-dataset附表署名-kimani-et-al-2023)｜✅｜鼻纹图像
    - 采集：沿用 C008 在自然活动条件下从围栏外、多距离与多角度拍摄形成的鼻部裁剪图。
    - 标注：按 268 个牛只身份分目录，监督目标为鼻纹图的个体身份分类。

- **C049**｜[Cattle Biometrics Dataset (Ahmed et al., 2024)](#c049cattle-biometrics-dataset-ahmed-et-al-2024)｜✅｜按身份组织的牛脸 / 鼻部 RGB 图像
    - 采集：在牛市场与农场使用相机及手机拍摄牛脸 / 鼻部，采集跨越数月，供鼻部生物特征识别使用。
    - 标注：个体身份由目录区分；论文另以单类 `muzzle` 框定位鼻部。

    - 采集：图像为保定设施中的正面牛脸，提供面部外观识别输入。
    - 标注：编号目录对应 91 个牛只身份类别，监督目标为图像级牛脸身份分类。

- **C039**｜[Cattle Face Recognition Dataset (Xiao et al., 2025)](#c039cattle-face-recognition-dataset-xiao-et-al-2025)｜✅｜裁剪牛脸图像
    - 采集：从吉林省三处牧场采集牛脸，并提供局部裁剪图用于面部识别。
    - 标注：筛选表记录牛脸框及类别标签，框为 LabelImg XML。

    - 采集：与 C049 同源，在牛市场与农场用相机及手机拍摄牛脸 / 鼻部。
    - 标注：目录提供个体身份类别；论文所述鼻部 YOLO 框服务于局部定位，身份识别使用目录标签。

**视网膜血管 / 眼底**（2 条）

- **C007**｜[CattNISDB dataset (Saygılı et al., 2024)](#c007cattnisdb-dataset-saygılı-et-al-2024)｜✅｜彩色视网膜图像
    - 采集：用数字眼底相机分别采集同一牛只的左右眼视网膜，以眼底血管等生物特征进行身份匹配。
    - 标注：牛号对应个体身份，`R` / `L` 区分右眼 / 左眼；`animal_info.xlsx` 的 ID 可关联个体记录。

    - 采集：与 C007 使用同一眼底图像发布源，分别采集左右眼，后续研究从原始集筛选优质图像进行识别。
    - 标注：牛号提供身份类别，`R` / `L` 提供眼别。

**俯视花斑 · 躯干匹配**（4 条）

- **C056**｜[OpenCows2020 dataset (Andrew et al., 2021)](#c056opencows2020-dataset-andrew-et-al-2021)｜✅｜俯视牛躯干 RGB 图像及身份裁剪图
    - 采集：整合室内固定相机与室外无人机的俯视影像，以牛背花斑进行身份匹配，覆盖不同背景、尺度与光照。
    - 标注：个体身份标签关联牛躯干裁剪图，附交叉验证划分；躯干框用于定位识别区域。

- **C057**｜[Cows2021 dataset (Gao et al., 2021)](#c057cows2021-dataset-gao-et-al-2021)｜✅｜俯视视频及方向校正的牛躯干 RGB 裁剪图
    - 采集：相机固定在挤奶厅与等候栏之间通道正上方，牛只通过时触发录像，采集俯视牛背外观。
    - 标注：个体身份关联有向躯干框及按时间组织的裁剪图，方向校正减少牛背花纹匹配中的朝向变化。

- **C058**｜[FriesianCattle2017 dataset (Andrew et al., 2017)](#c058friesiancattle2017-dataset-andrew-et-al-2017)｜✅｜方向校正的俯视 RGB 静态 JPG，按牛只个体身份目录组织
    - 采集：Kinect 2 固定在待挤栏与挤奶站之间通道正上方，以 0.5 Hz 记录牛背花纹。
    - 标注：图像按牛只身份分目录，方向校正后的躯干图用于花斑匹配与个体分类。

- **C061**｜[FriesianCattle2015 dataset (Andrew et al., 2016)](#c061friesiancattle2015-dataset-andrew-et-al-2016)｜✅｜去背景、旋转校正的俯视牛背 RGB 图像
    - 采集：Kinect 2 从挤奶通道正上方采集 RGB-D，借助深度去背景并对齐方向，保留牛背花纹用于识别。
    - 标注：目录编码图像级个体身份，公开识别图已预先去背景。

**通道 / 侧视视频**（5 条）

- **C003**｜[Beef identify dataset (Qiao et al., 2021)](#c003beef-identify-dataset-qiao-et-al-2021)｜✅｜视频抽帧 RGB 图像
    - 采集：牛只沿育肥场通道行走时，用后视相机记录连续图像，以后方外观序列进行身份识别。
    - 标注：共 50 个牛只身份，以耳标人工核对；每段序列对应一个个体。

- **C006**｜[RecBov51c dataset (Weber et al., 2020)](#c006recbov51c-dataset-weber-et-al-2020)｜✅｜视频抽帧图像
    - 采集：四台通道出口相机从背部、轮廓、侧面和脸部拍摄牛只，视频抽帧形成多视角身份图像。
    - 标注：图像级个体身份标签共 51 类。

- **C047**｜[Holstein Cattle Side-View Benchmark Dataset (Bhole et al., 2019)](#c047holstein-cattle-side-view-benchmark-dataset-bhole-et-al-2019)｜✅｜同次拍摄配对的牛只侧视 RGB 与红外热图像
    - 采集：牛只离开挤奶站时，以同一设备配对采集地面侧视 RGB 与红外热图，供侧面外观及跨模态身份识别使用。
    - 标注：136 个身份类别，文件夹名对应项圈 ID，同次拍摄的 RGB 与热图关联到同一身份。

- **C048**｜[Holstein cattle side-view RGB-thermal dataset (Bhole et al., 2022)](#c048holstein-cattle-side-view-rgb-thermal-dataset-bhole-et-al-2022)｜✅｜侧视 RGB 与热成像配对身份图像
    - 采集：在挤奶站出口用固定 FLIR E6 同步拍摄侧视 RGB 与热图，跨 9 天记录同一牛群。
    - 标注：383 个牛只身份，文件名编码牛号、采集日与图序，`timestamp.xlsx` 提供日号对应关系。

- **C132**｜[RecBov51c（Mendeley v7）](#c132recbov51cmendeley-v7)｜✅｜牛只通道视频抽取的彩色 JPG，按牛只类别目录组织
    - 采集：与 C006 同一通道多视角采集来源，四台相机记录背部、轮廓、侧面和脸部，本条为 v7 发布。
    - 标注：按 51 个牛只身份分目录，监督目标仍为图像级身份分类。

    - 采集：发布图像用于个体身份分类。

### 2. 整牛检测 / 计数（23 条）

> 整牛检测是在图像中找出每头牛的位置，通常输出矩形框；计数则统计画面中的牛只数量，也可以使用逐牛点标注。数据常来自牛舍监控、地面拍摄或无人机航拍，目标大小、遮挡程度和拍摄角度差异较大。检测常作为跟踪、行为分析和自动盘点的前置步骤；本节同时包含躯干框、点标注和有牛 / 无牛分类候选。

**无人机 · 航拍俯视**（6 条）

- **C009**｜[UAV Cattle Pasture Datasets (Shao et al., 2020)](#c009uav-cattle-pasture-datasets-shao-et-al-2020)｜✅｜航拍 RGB 图像
    - 采集：无人机俯拍牧场，其中 Dataset1 高度约 50 m；重叠图像可重复出现同一牛只，适合航拍小目标检测与计数。

### 4. 体尺 · 体重测量（10 条）

> 体尺测量估计牛只的体长、体高、胸围等尺寸，体重估计则根据外观或三维形状预测重量，服务于生长监测与非接触测量研究。输入可为侧视 / 背视照片、深度图或点云，通常需要尺度参考，以及与同一牛只对应的人工体尺或称重记录。体尺关键点和轮廓可辅助提取几何信息。

### 8. 疾病 · 健康诊断（7 条）

> 疾病与健康视觉分析研究能否从牛体外观、行走步态、眼底或超声影像中识别健康相关异常，例如皮肤病分类和跛行程度评估。不同问题需要相应的疾病类别、专家评分或检查结果作为参照。本节既有明确疾病标签的数据，也有健康相关影像候选。

### 9. 体况评分 BCS（6 条）

> 体况评分（Body Condition Score，BCS）评估牛只的胖瘦和身体储备状况，与直接预测体重不同，输出通常是一个等级或分数。视觉方法利用背部、腰臀等区域的外观或深度形状，以人工评分为参照建立预测模型。本节包含不同评分刻度及 RGB-D / 深度输入，使用时需保留评分体系、分档和个体对应关系。

- **C050**｜[Livestock body condition score datasets（作者项目 LShapeAnalyser）](#c050livestock-body-condition-score-datasets作者项目-lshapeanalyser)｜✅｜牛只单通道深度 PNG 图像，附体况评分（BCS）
    - 采集：Kinect V2 从牛体后方斜视采集深度形状，以背部 / 后躯几何外观评估体况。
    - 标注：`BCS_dairy.txt` 为 203 张深度图提供评分，取值为 2.50、2.75、3.00、3.25、3.50。

- **C054**｜[Raramuri Criollo cattle body condition score dataset (Winkler et al., 2024)](#c054raramuri-criollo-cattle-body-condition-score-dataset-winkler-et-al-2024)｜✅｜通道俯视 RGB-D 录像与 DGE TIFF
    - 采集：RealSense D435i 从约 2.5 m 高处俯拍通道牛只，派生深度、灰度、边缘三通道 DGE 图像作为体况输入。
    - 标注：四位受训评委按 1–9 整数分独立评分并汇总，发布图像 / 录像覆盖 BCS 2–6，另含 17 张 BCS 7。

- **C090**｜[Livestock 3D Body Condition Assessment Dataset (Zhang et al., 2023)](#c090livestock-3d-body-condition-assessment-dataset-zhang-et-al-2023)｜✅｜与 C050 同源的牛体深度图及 BCS
    - 采集：沿用 C050 后方斜视深度采集，利用牛体三维形状分析体况。
    - 标注：203 个图像级 BCS 为 2.50、2.75、3.00、3.25、3.50，各有 1、36、75、79、12 条。

- **C106**｜[Cattle Body Condition Score](#c106cattle-body-condition-score)｜✅｜处理后的 DGE TIFF 图像（深度、灰度、边缘通道）
    - 采集：RealSense 俯拍通道形成 RGB-D 来源，再转换为深度、灰度、边缘三通道 DGE 图像。
    - 标注：以 BCS 数值目录提供图像级评分类别；README 称转换时丢弃个体身份。

- **C110**｜[Direct measurement of dairy cow body condition using a 3D camera](#c110direct-measurement-of-dairy-cow-body-condition-using-a-3d-camera)｜✅｜牛背部 3D 帧、每台相机对应的彩色图像及 CSV
    - 采集：牛只在称重栏中被拍摄背部 3D 帧，背部形状与体况评估有关，另存彩色参考图。
    - 标注：已读 CSV 含牛号、时间、帧号及几何测量。

- **C112**｜[Labeled RGB and depth images for cattle body condition score prediction](#c112labeled-rgb-and-depth-images-for-cattle-body-condition-score-prediction)｜✅｜与 C054 同源的 RGB-D 录像及 DGE TIFF
    - 采集：与 C054 同源，RealSense D435i 俯拍通道。
    - 标注：录像 / 图像对应 1–9 分制 BCS，发布覆盖 2–6 分并含 17 张 7 分图。

### 10. 多物种通用动物（6 条）

- **C096**｜[Animals Detection Images Dataset](#c096animals-detection-images-dataset)｜✅｜多动物类别 RGB 图像及同名 TXT 矩形框标注，发布者说明从 Google Open Images V6+ 提取
    - 采集：从 Open Images V6+ 汇集多动物图像，牛相关样本既有多牛栏舍场景，也有牛头局部特写。

- **C098**｜[Cattle Dataset (Pig, Sheep, Cow, Horse)](#c098cattle-dataset-pig-sheep-cow-horse)｜✅｜多动物图像与类别化实例多边形

    - 标注：两版均为 `COW / horse / pig / sheep / undefined` 五类，`COW=0`；监督为实例多边形。

- **C102**｜[Open Images V7 Animals YOLO](#c102open-images-v7-animals-yolo)｜✅｜多动物类别图像，发布者描述为 Open Images V7 子集，数据集标题标为 YOLO
    - 采集：从 Open Images V7 选择动物图像，是多来源网络子集。
    - 标注：配置共 11 类，牛相关为 `Cattle=2`、`Bull=8`。

- **C104**｜[Wildlife Aerial Imagery Dataset](#c104wildlife-aerial-imagery-dataset)｜✅｜多物种无人机航拍图像，发布者说明含 10 个动物类别，Cattle 为其中一类

- **C124**｜[M-Vet Livestock Dataset（v2.0.0）](#c124m-vet-livestock-datasetv200)｜✅｜九分包多物种 JPG、点序列 TXT 与类别 YAML

- **C130**｜[Animal Action Video Dataset with Heatmap and Silhouette Representations](#c130animal-action-video-dataset-with-heatmap-and-silhouette-representations)｜✅｜25 类动物视频及派生热图、剪影
    - 采集：每类动物对应视频来源，其中牛类为 1 段户外行走视频。

### 11. 三维重建 · RGB-D（4 条）

> RGB-D 同时记录彩色图像（RGB）与深度（Depth），可将可见牛体表面表示为三维点云；多视角重建进一步把不同方向的几何数据配准、融合。相比普通照片，这类数据保留空间形状，可用于体尺测量、体况分析或基于形状的身份研究。本节既有左 / 右 / 顶部三视角方案，也有单一顶部机位。

- **C014**｜[3D body model dataset for Aberdeen-Angus cattle (Ruchay et al., 2022)](#c0143d-body-model-dataset-for-aberdeen-angus-cattle-ruchay-et-al-2022)｜✅｜RGB + 深度图 + 点云
    - 采集：三台 Kinect v2 从左、右与顶部同步采集行走牛只的 RGB-D，各视角提供互补牛体表面。
    - 标注：每牛按编号组织三视角 RGB、深度、原始点云及融合 `aligned.ply`，支持多视角重建。

- **C027**｜[CowDepth2023 (Sharma et al., 2024 预印本 / 2025 期刊版)](#c027cowdepth2023-sharma-et-al-2024-预印本--2025-期刊版)｜✅｜同步 RGB—深度图像对及对应点云，按牛只个体身份组织
    - 采集：单台顶部 Kinect V2 同步记录通道牛背 RGB 与深度，提供俯视表面几何。
    - 标注：RGB、深度、点云按时间戳及牛只身份对应，分割与裁剪由深度处理生成。

- **C028**｜[CowDatabase3 (Ruchay et al., 2025)](#c028cowdatabase3-ruchay-et-al-2025)｜✅｜三视角 RGB-D、原始点云及融合点云
    - 采集：三台 Kinect V2 以 30 fps 同步采集牛只左、右与顶部视图，获得多侧面牛体几何。
    - 标注：目录 / 帧号与表格路径对应各视角图像、原始点云和融合点云，可追溯重建输入。

- **C059**｜[CowDatabase (Ruchay et al., 2020)](#c059cowdatabase-ruchay-et-al-2020)｜✅｜三视角 RGB-D / PLY 与相机间变换矩阵
    - 采集：在饲喂围栏附近用三台深度相机拍摄牛只左、右及顶部，提供原始与融合几何。
    - 标注：三视角时间戳及 `Left -> Top / Right -> Top` 两个 4×4 变换矩阵支持跨视角配准，编号关联各视角 PLY 与融合点云。

### 12. 肉质 · 胴体品质（4 条）

> 肉质与胴体品质分析关注屠宰后的胴体或肉块。任务包括根据颜色、纹理等外观区分新鲜程度，预测胴体等级，或研究热成像与温度、pH 等测量指标的关系。输入常为肉块近景、胴体照片或红外热图，标签可能是图像级品质类别或连续测量值。

- **C021**｜[AI Hub dataset (Lim & Song, 2025)](#c021ai-hub-dataset-lim--song-2025)｜⚠️｜RGB 图像 + 分割掩膜

    - 标注：图像关联 `1++ / 1+ / 1 / 2 / 3` 五档等级，分割掩膜为区域提取辅助。

- **C022**｜[Meat Freshness Image Dataset (Büyükarıkan, 2024)](#c022meat-freshness-image-dataset-büyükarıkan-2024)｜✅｜RGB 肉块近景图像，用于肉类新鲜度分类
    - 采集：肉块表面近景照片提供颜色与纹理外观，用于新鲜程度分类。
    - 标注：`_classes.csv` 为每图给出 Fresh、Half-Fresh、Spoiled 三类中的一个标签，不提供肉质区域框。

- **C069**｜[MeatScan dataset (Gyening et al., 2025)](#c069meatscan-dataset-gyening-et-al-2025)｜✅｜生牛肉块的 RGB 静态图像及图像级 fresh / spoiled 标签
    - 采集：手机在露天市场、肉铺与冷库拍摄生牛肉块，覆盖自然光、环境光及荧光灯下的新鲜度外观。

- **C122**｜[Infrared thermal images and corresponding pH, temperature, and hot carcass weight measurements of beef carcasses](#c122infrared-thermal-images-and-corresponding-ph-temperature-and-hot-carcass-weight-measurements-of-beef-carcasses)｜✅｜屠宰后左半胴体的红外热成像 JPG，附冷却前后 pH、温度、热胴体重及性别测量表
    - 采集：拍摄屠宰后左半胴体红外热图，关联冷却前后品质测量；记录的侧表面与包内 `dorsal view` 表述有差异。

### 13. 部位 / 局部检测（3 条）

> 部位 / 局部检测寻找鼻部、耳标、牛脸、眼或耳等局部区域。它通常先用矩形框定位并裁剪目标，再交给鼻纹识别、耳标号码读取或面部分析模型，因此常是完整系统的前置步骤。核心标注是部位类别与区域位置。

- **C072**｜[Cow Ear Tag Detection Dataset / Cow Ear Tag Recognition Dataset (Gao et al., 2024)](#c072cow-ear-tag-detection-dataset--cow-ear-tag-recognition-dataset-gao-et-al-2024)｜✅｜CEID-D 的 RGB 牛群场景 JPG + 耳标框 TXT；CEGD-R 的灰度耳标裁剪 JPG + 号码文本区域 TXT
    - 采集：在牛舍内与户外从正面、侧面及上方拍摄牛只，覆盖不同天气、光照与姿态下耳标可见性的变化。
    - 标注：CEID-D 为单类耳标水平框；CEGD-R 另提供号码四点文本区域与字符串真值，前者定位耳标，后者用于号码识别。

    - 采集：正面近距离拍摄牛鼻特写，部分含人工扶持，目标是局部鼻部。
    - 标注：单类 `Muzzle` 鼻部框，采用五列归一化 YOLO 格式。

- **C129**｜[Annotated Cattle Images（ACI）dataset](#c129annotated-cattle-imagesacidataset)｜✅｜从互联网图像平台汇集的彩色 JPG，附牛脸及眼、耳、口鼻等面部子区域的矩形框 TXT
    - 采集：从网络图像平台汇集多角度牛脸，含侧脸、低头、人员交互及围栏遮挡，供面部子区域定位。
    - 标注：类别 ID 0–5 的 YOLO 矩形框定位牛脸、眼、耳及口鼻等区域。

### 15. 品种分类（3 条）

> 品种分类回答「这头牛属于什么品种」，根据毛色、体型、头部等外观信息给图像分配品种类别。它与个体身份识别的区别在于同一品种下的多头牛共享一个类别。数据通常按品种目录组织，或通过表格提供图像级标签；拍摄角度、遮挡及背景差异会影响外观判断。

- **C092**｜[Indian Cattle Image Dataset](#c092indian-cattle-image-dataset)｜✅｜RGB 图像
    - 采集：发布者称按官方品种标准汇集机构来源图像，面向印度牛种的外观分类。
    - 标注：品种目录提供图像级标签，`metadata.csv` 的 `breed` 对应品种，另有图像 ID、地区、来源与年份字段。

- **C103**｜[Indian Cattle Breeds](#c103indian-cattle-breeds)｜✅｜牛种分类图像
    - 采集：公开图像按印度牛种组织。
    - 标注：品种目录提供图像级类别，监督目标为品种分类。

### 16. 放牧 · 牧场遥感（1 条）

> 放牧与牧场遥感把观察对象从单头牛扩展到草场，利用无人机多光谱影像及植被指数描述放牧前后的植被变化，再结合 GPS 轨迹和行为观察研究牛只活动与草场的关系。它属于场地尺度的监测，本节的影像、轨迹和观察记录属于不同数据层。

- **C036**｜[Cattle Grazing Behavior and Vegetation Dynamics Dataset (Wang et al., 2025b)](#c036cattle-grazing-behavior-and-vegetation-dynamics-dataset-wang-et-al-2025b)｜✅｜多光谱无人机航拍图像（蓝、绿、红、红边、近红外波段），另含 GPS 轨迹与行为观察记录

    - 标注：GPS 含时间戳与经纬度，人工记录采食、站立、行走、休息、反刍。

### 17. 挤奶 / 乳头视觉（1 条）

> 挤奶 / 乳头视觉关注挤奶过程中的乳房和乳头区域，可研究如何选择清晰、无遮挡的画面，以及如何为后续部位定位与操作分析提供输入。视频中杯组、转盘运动和光照变化会影响目标可见性，因此关键帧选择与乳头定位是不同的子任务。本节现有数据直接支持关键帧选择评测。

- **C071**｜[CowTeatVideo Benchmark (Zhang et al., 2022)](#c071cowteatvideo-benchmark-zhang-et-al-2022)｜✅｜挤奶转盘上牛只乳房 / 乳头区域的 RGB 视频（MP4），另附 32 张关键帧参考图像的 MATLAB 数组
    - 采集：固定机位及补光对准旋转挤奶厅中牛只后方乳房 / 乳头区域，重点记录杯组脱离后可供分析的影像。
    - 标注：32 张支持关键帧及视频级关键帧数量用于关键帧评测，并经专家核查。
