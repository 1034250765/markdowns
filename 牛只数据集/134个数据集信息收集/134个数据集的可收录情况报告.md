# 134 个牛类数据集可收录情况报告

> 范围：CowCV 候选数据集清单 134 条（同目录 `cowcv_ruchay2026_screening.xlsx`）。逐条给出数据集名称、源数据形态、数据入口、规模、采集条件、标注类型与文献出处，并给出收录判定。

## 一、总体结论

| 标记       | 条数  | 含义                             |
| -------- | --- | ------------------------------ |
| ✅ 可收录    | 94  | 源数据是图像/视频，且数据可下载               |
| ⚠️ 有条件收录 | 6   | 源数据是图像/视频，但需登录、申请、机构账号或网盘提取码   |
| ❌ 不可收录   | 34  | 源数据不是图像/视频；或数据取不到；或重复；或许可禁止再分发 |

❌ 的 34 条构成：源数据不是图像/视频 15 条，图像/视频但数据取不到 16 条，重复 2 条（C040、C134），许可禁止再分发 1 条（C060）。

**收录口径**：只看源数据格式——图像（RGB / 深度 / 热成像 / 多光谱 / 超声 / 视网膜 / 卫星 / 航拍）或视频即具备收录资格；纯传感器时序、音频、GPS/数值表、点云不具备资格。数据能否实际取得同时计入最终标记。

**标记含义**：

- ✅ 可收录：源数据是图像/视频，且数据可下载——公开直链，或用 Kaggle 账号经 API 拉取。
- ⚠️ 有条件收录：源数据是图像/视频，但需登录、申请、机构账号或网盘提取码。
- ❌ 不可收录：源数据不是图像/视频；或虽是图像/视频但数据取不到（链接失效、仓库无数据、数据集已删除）；或许可明确禁止再分发（C060 的 CattleEyeView）。

**判定细则**：作者主动只公开子集、公开部分可下载且为图像/视频时仍记 ✅（C091）；全量入口失效、只剩少量样图记 ❌（C055）。

上表为条目标记数量，不是去重后的独立数据集数量；同源关系见第五节，各条的许可归属与分布见第七节。

### C002｜Cattle Retinal Fundus Image dataset (Cihan et al., 2024)

**收录判定**：✅ 可收录
**源数据形态**：RGB 视网膜图像
**数据入口**：https://www.kaggle.com/datasets/animalbiometry/cvd-vs-noncvd-retinal-images-of-cattle
**规模**：100 头牛、1,118 张视网膜图像；52 头患心血管疾病（CVD）、48 头为非 CVD，对应 591 张与 527 张。
**图像与数据量**：RGB 彩色眼底图像，JPG，1536×1152，合计约 1.20 GB。
**采集视角 / 设备**：分别采集左右眼眼底，使用 Optomed Smartscope 数字眼底相机。
**标注类型**：图像级二分类标签，目录 `0` = non-CVD（527 张）、`1` = CVD（591 张）。
**出处**：Cihan, P., Saygılı, A., Ermutlu, C. Ş., Aydın, U., & Aksoy, Ö. (2024). *AI-aided cardiovascular disease diagnosis in cattle from retinal images: Machine learning vs. deep learning models*. *Computers and Electronics in Agriculture*, **226**, 109391. DOI: `10.1016/j.compag.2024.109391`。
**论文链接**：[DOI / 论文原文入口](https://doi.org/10.1016/j.compag.2024.109391)；[ScienceDirect 出版商页面](https://www.sciencedirect.com/science/article/pii/S0168169924007828)。

### C003｜Beef identify dataset (Qiao et al., 2021)

**收录判定**：✅ 可收录
**源数据形态**：视频抽帧 RGB 图像
**数据入口**：[GitHub 仓库](https://github.com/qiao19881314/beefidentify)（仓库为代码；数据经 README 的 Google Drive 链接发布，文件 `data.zip`）
**规模**：50 头牛、363 段视频序列，每段 40 帧，共 14,520 帧；分三批采集，日期为 2018-03-20、2018-04-30、2018-05-30。
**图像与数据量**：原始采集 1920×1080、30 fps，实验使用中央裁剪的 401×506 像素 ROI；`data.zip` 为 6,527,828,637 字节（约 6.53 GB）。
**采集视角 / 设备**：澳大利亚昆士兰州南部商业育肥场的通道内，牛向保定架行走时采集后视图，使用后视 ZED 相机左目图像。
**标注类型**：牛只个体身份标签（50 类），真实身份按耳标人工记录，每段序列对应一个个体。
**出处**：Qiao, Y., Clark, C., Lomax, S., Kong, H., Su, D., & Sukkarieh, S. (2021). *Automated Individual Cattle Identification Using Video Data: A Unified Deep Learning Architecture Approach*. *Frontiers in Animal Science*, **2**, 759147. DOI: `10.3389/fanim.2021.759147`。
**论文链接**：[DOI / 论文原文入口](https://doi.org/10.3389/fanim.2021.759147)；[Frontiers 开放获取全文](https://www.frontiersin.org/journals/animal-science/articles/10.3389/fanim.2021.759147/full)。

### C004｜Cattle muzzle biometric dataset (Shojaeipour et al., 2021)

**收录判定**：✅ 可收录
**源数据形态**：高分辨率 RGB 图像
**数据入口**：https://cloud.une.edu.au/index.php/s/eMwaHAPK08dCDru
**规模**：论文第 2.1.2 节记录 300 头混合品种肉牛、2,900 张原始牛脸 / 鼻部图像（Angus、Hereford、Charolais、Simmental）；268 张（9.24%）未拍到鼻部或严重模糊，个体识别使用 2,632 张有效鼻部裁剪图，训练 / 验证 / 测试为 1,500 / 569 / 563 张。
**图像与数据量**：原始图像为 RGB JPEG，4000×6000 像素；分享根目录含 `300_Cattle_list.docx`、`Citation.txt`、`yolov3-obj.cfg` 与 `300-Cattle-source/`（300 个牛号文件夹 001–300），单张 JPG 约 6.3 MB。
**采集视角 / 设备**：2019 年 2 月在澳大利亚新英格兰大学 Tullimba Research Feedlot 采集；牛在保定架及头部托架约束下，摄影者位于正前方约 1–2 m、高度约离地 1 m，采集正面牛脸并将焦点置于鼻部；Canon D800 与 EF-S 18–55 mm 镜头，连拍约 6 张/秒，晴天自然光，时段 08:00–16:00。
**标注类型**：VoTT 标注鼻部矩形框用于 YOLOv3 检测与裁剪，裁剪后图像带 300 类个体身份标签。
**出处**：Shojaeipour, A., Falzon, G., Kwan, P., Hadavi, N., Cowley, F. C., & Paul, D. (2021). *Automated Muzzle Detection and Biometric Identification via Few-Shot Deep Transfer Learning of Mixed Breed Cattle*. *Agronomy*, **11**(11), 2365. DOI: `10.3390/agronomy11112365`。

### C005｜CVB dataset (Zia et al., 2023)

**规模**：8 头 Angus 肉牛、502 段 15 秒视频（每段 450 帧），共 225,900 个标注帧，含 11 种视觉可辨行为。

**标注类型**：逐帧牛只矩形框 + 视频内一致的个体跟踪 ID + 11 类互斥行为（grazing、walking、running、ruminating-standing、ruminating-lying、resting-standing、resting-lying、drinking、grooming、other、hidden），由领域专家在 CVAT 中修正。
**出处**：Zia, A., Sharma, R., Arablouei, R., Bishop-Hurley, G., McNally, J., Bagnall, N., Rolland, V., Kusy, B., Petersson, L., & Ingham, A. (2023). *CVB: A Video Dataset of Cattle Visual Behaviors*. arXiv:2305.16555v2. DOI: `10.48550/arXiv.2305.16555`；数据集 DOI `10.25919/3g3t-p068`。

### C008｜Beef Cattle Muzzle Image Dataset (Li et al., 2022a)

**收录判定**：✅ 可收录
**源数据形态**：RGB 图像（鼻纹）
**数据入口**：https://doi.org/10.5281/zenodo.6324360
**规模**：先从 400 头美国混种育肥牛采集 4,531 张原始照片，经旋转、鼻部裁剪与质量筛选形成 268 头牛、4,923 张鼻部图像（每头 4–70 张）；实验按 65% / 15% / 20% 随机划分训练 / 验证 / 测试。
**图像与数据量**：公开的是清洗、裁剪后的 RGB 鼻部图像，裁剪尺寸不一，实验统一缩放为 300×300；固定版本 `6324361` 含 `BeefCattle_Muzzle_database.zip`，643,745,309 字节（约 643.75 MB）。

**标注类型**：鼻部裁剪图的牛只个体身份标签，共 268 类；原始采集时以耳标验证身份。
**出处**：Li, G., Erickson, G. E., & Xiong, Y. (2022). *Individual Beef Cattle Identification Using Muzzle Images and Deep Learning Techniques*. *Animals*, **12**(11), 1453. DOI: `10.3390/ani12111453`；数据固定版本 DOI `10.5281/zenodo.6324361`。

### C009｜UAV Cattle Pasture Datasets (Shao et al., 2020)

**收录判定**：✅ 可收录
**源数据形态**：航拍 RGB 图像
**数据入口**：https://bird.nae-lab.org/cattle/
**规模**：Dataset1 为 656 张图、1,886 个牛只框、212 个个体目标；Dataset2 为 14 张图、62 个框、6 个个体目标，合计 670 张图、1,948 个框、218 个个体目标（镜像清单记 1,949 个框）。同一目标会出现在多张重叠航拍图中。
**图像与数据量**：无人机静态摄影模式采集，Dataset1 原图为 4000×3000；可通过 Dataset Ninja 镜像取得转换为 Supervisely 格式的数据，镜像 TAR 包约 3.53 GB。
**采集视角 / 设备**：DJI Phantom 4 在日本熊本县阿苏牧场俯视航拍。Dataset1 于 2016-05-18 晴天采集，7 次飞行，高度约 50 m，每张覆盖约 80 m×60 m，重叠率 80%，约 2 s 间隔停走拍摄；Dataset2 于 2016-08-24 在同一牧场另一区域飞行 1 次，约每 6 s 一张。
**标注类型**：单类 `cattle` 矩形框，原始字段含框左上角位置、宽、高、个体 ID 与质量标签（Normal、Truncated、Blurred、Occluded）；同一次飞行内同一目标保持同一 ID。
**出处**：Shao, W., Kawakami, R., Yoshihashi, R., You, S., Kawase, H., & Naemura, T. (2020). *Cattle detection and counting in UAV images based on convolutional neural networks*. *International Journal of Remote Sensing*, **41**(1), 31–52. DOI: `10.1080/01431161.2019.1624858`。
**论文链接**：[DOI / 论文原文入口](https://doi.org/10.1080/01431161.2019.1624858)；[Taylor & Francis 出版商页面](https://www.tandfonline.com/doi/full/10.1080/01431161.2019.1624858)。

### C012｜Aerial Livestock Dataset (Han et al., 2019)

**收录判定**：✅ 可收录
**源数据形态**：航拍 RGB 图像
**数据入口**：[GitHub 仓库](https://github.com/hanl2010/Aerial-livestock-dataset/releases)
**规模**：89 张航拍图、4,996 个 livestock 实例，分 Part I / II / III，分别为 29 / 17 / 43 张。论文将不同牲畜统一标为 `livestock`；实验仅使用 Part III，按 36 张训练、7 张测试。
**图像与数据量**：论文称原图约 3000×4000 像素，单个目标约 20×20 至 40×40 像素；U-net 实验切为 224×384 小图后得到训练 2,716 张、测试 348 张。Release 1.0 提供三个 RAR（`Part_I.rar`、`Part_II.rar`、`Part_III.rar`），合计 262,148,369 字节（约 262.15 MB）。
**采集视角 / 设备**：四旋翼无人机空中拍摄草地上的牲畜；三部分按拍摄时间、地点与检测难度区分——Part I 背景简单，Part II 含地貌干扰，Part III 含不同毛色、密集遮挡目标及积雪、房屋干扰。
**标注类型**：统一 `livestock` 类的轴对齐矩形框，按 Pascal VOC 格式保存。
**出处**：Han, L., Tao, P., & Martin, R. R. (2019). *Livestock detection in aerial images using a fully convolutional network*. *Computational Visual Media*, **5**(2), 221–228. DOI: `10.1007/s41095-019-0132-5`。
**论文链接**：[DOI / 论文入口](https://doi.org/10.1007/s41095-019-0132-5)；[Springer 开放全文](https://link.springer.com/article/10.1007/s41095-019-0132-5)。
