# 134 个牛类数据集可收录档案（逐条）

> **收录口径**：只看源数据格式——图像（RGB / 深度 / 热成像 / 多光谱 / 超声 / 视网膜 / 卫星 / 航拍）或视频即具备收录资格；纯传感器时序、音频、GPS/数值表、点云不具备资格。**同时把「数据是否真的拿得到」计入最终标记**（这是 2026-10-21 实测的结论）。
>
> **标记含义**：
> - **✅ 可收录**：源数据是图像/视频，且数据确认可下载——公开直链，或用你自己的 Kaggle 账号经 API 拉取（本次 C002 已实测下载成功）。
> - **⚠️ 有条件收录**：源数据是图像/视频，但需登录、申请、机构账号、网盘提取码，或仓库只有代码+外链、路径需更正。
> - **❌ 不可收录**：源数据不是图像/视频；或虽是图像/视频但数据确认取不到（链接失效、仓库无数据、数据集已删除）；或**许可明确禁止再分发**、无法纳入本站（如 C060 的 CattleEyeView）。
>
> **核实时间**：2026-10-21 ｜ 清单来源：同目录 `cowcv_ruchay2026_screening.xlsx`（134 条）｜ 方法见文末。
>
> ⚠️ 本文件与《CowCV 候选数据集初筛-Ruchay 2026 补充材料 134 条》口径不同：那份按「单类整牛检测框」打 P0/P1/P2/X，本文件按「源数据格式 + 可获取性」判定，两套结论不能混用。

## 一、总体结论

- **✅ 可收录：95 条**
- **⚠️ 有条件收录：7 条**
- **❌ 不可收录：32 条**（其中 14 条源数据不是图像/视频，15 条是图像/视频但数据取不到，2 条重复（C040、C134），1 条许可禁止再分发（C060））

需要注意：**「源数据是图像/视频」不等于「能收录」**。134 条里有 15 条格式合格但数据入口断了、根本不存在或无法定位（C001、C010、C019、C020、C026、C029、C031、C037、C062、C063、C066、C067、C087、C089、C099），这些在早期只看附表的版本里被误记为「可下载」。另有 7 条属于「需申请／需登录／需机构账号」的有条件收录（C021、C035、C038、C042、C043、C076、C088），可拿到但不等于可直接分发。还有 1 条（C060 CattleEyeView）数据能申请到，但条款禁止再分发，无法进自建服务器。C134 与 C036 是同一个仓库，按重复处理、不单独收录。

## 七、核实方法与局限

**做过什么**：

1. 逐条读附表 `modality` / `annot` / `size`，确定源数据形态；
2. DOI 类记录走 DataCite API（62 条），拿到许可、资源类型、摘要、体积；
3. Zenodo 31 条走 `zenodo.org/api/records/<id>`，拿到真实文件数、体积、首个文件名；对内容有疑问的记录（如 C025/C040）把 zip 实际下载后解开，核对里面到底是什么文件类型；
4. Mendeley 14 条走 `data.mendeley.com/public-api`，拿到文件列表；
5. data.bris 5 条读数据集页，拿到许可、体积、完整 zip 入口；
6. GitHub/Gitee 35 条逐个打开，解析根目录文件列表、README、Release，并抽测 README 里的 Google Drive / 百度网盘链接；
7. **Kaggle 26 条走 Kaggle API**（用你机器上的 `~/.kaggle/kaggle.json` 凭据）：24 条返回 200，拿到许可、体积、文件数、更新时间、下载量；2 条返回 403（C052、C099，疑似已删除）。其中 C002 另做了文件级实测：单文件下载 200 且 JPG 魔数正确，整包 zip 的 Range 请求返回 206 且带 PK 头。
8. **C002 另做了页面级复核**：用 Playwright 的 `connectOverCDP` 连上你本机启动的 Chrome（9222 调试端口），读取渲染后的页面。说明：本环境禁止*启动*浏览器（沙箱拦截 Chrome 的命名管道），但*连接*已运行的浏览器可行——CDP 走的是 127.0.0.1 的 WebSocket，不涉及管道。

**没做什么（别当成已核实）**：

1. 没有下载、解压、抽检任何数据集；
2. 仓库只看了根目录 1 层，没逐层展开子目录；
3. Kaggle 25 条的许可与文件清单仍是空白；
4. 附表声称的图像数与真实文件数未逐一比对；
5. 百度网盘链接只验证到「分享页可达」，没验证提取码与文件是否还在。

**环境限制**：本机 `zenodo.org` 网页域名 DNS 不可达（改用 DataCite + Zenodo API 绕开）；Kaggle 全站人机验证；`hdl.handle.net`、ownCloud 分享页对自动访问返回 403 或空壳；`bird.nae-lab.org` 已 502；`archive.org` 的 C026 条目已 404。
