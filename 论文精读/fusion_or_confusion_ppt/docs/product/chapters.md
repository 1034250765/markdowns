## 播放方式（网页版）

启动：`cd frontend && npx vite --port 5173 --host 127.0.0.1`，打开 `http://localhost:5173/`

| 操作 | 效果 |
|---|---|
| `F` 键 / 右下角圆形按钮 | 进入 / 退出全屏 |
| `Esc` | 退出全屏 |
| `→` / 空格 / 点击画面右侧 75% | 下一页 |
| `←` / 点击画面左侧 25% | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| `?page=14` | 直接跳到第 14 页 |

全屏时按 `min(宽/1440, 高/810)` 等比放大填满屏幕，不留黑边、不裁切。

## 修改方式

- 单页内容：改 `frontend/src/slides/slide-N.js`（N 与页码一致，1–26）
- 全局配色/字体：改 `frontend/index.html` 的 `:root` 变量与 `docs/page-global-config.json`
- 重新导出（插件路径以本机实际缓存为准）：
  ```bash
  cd frontend
  node scripts/build-slides.js
  node "<插件>/skills/ppt-implement/scripts/export/html2pptx.js" ./dist-slides/all-slides.html ../artifacts/presentation.pptx
  ```
