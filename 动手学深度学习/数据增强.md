## 图像增广
``` python
import torch
import torchvision
from torch import nn

img = PIL.open(.jpg)
img.show()

#torchvision 中有很多的数据增广函数
torchvision.transforms.RandomVerticaFlip()        #随机上下翻转

torchvision.tansforms.RandomResizedCrop((200,200))#随机裁剪  （目标区域大小）（多大的裁剪）（高宽比）

torchvision.tansforms.ColorJitter(brightness=0.5, contrast, saturation, hue)#随机颜色亮度变化
```
