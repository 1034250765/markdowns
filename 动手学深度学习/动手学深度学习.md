训练误差：模型在训练数据集上的误差

**K-则交叉验证**：在没有足够多的数据时应用

```cmd
把数据分成 K 份，轮流拿其中一份做验证集，其余 K-1 份做训练集。
过程如下：
将数据随机划分为 K 个子集。
第 1 轮：第 1 份验证，其余训练。
第 2 轮：第 2 份验证，其余训练。
重复 K 轮，让每一份数据都当过一次验证集。
将 K 次指标取平均。
```

直观地说，它比一次固定的训练集/验证集划分更稳定，因为模型不是只在某一份验证集上测试，而是在多种数据划分上测试。



将训练数据分为K块

for i in range（k）

使用第i块作为验证数据集，其余作为训练数据集。

## 权重衰退

L2 正则化的作用是：在训练时惩罚过大的权重，让模型倾向于使用更平滑、更简单的参数组合，从而降低过拟合风险。

它带来的主要效果

1. **减少过拟合**

模型不容易依赖少数特别大的权重去记忆训练样本，因此通常具有更好的验证集和测试集表现。

1. **让模型更平滑**

权重较小时，模型对输入的小变化通常不会过于敏感，决策边界更平滑。

1. **提高训练稳定性**

大权重可能导致激活值、梯度或损失变得很大。L2 正则可以抑制这种情况。

1. **缓解参数不适定**

当多个参数组合都能得到类似训练损失时，L2 会偏向选择整体权重范数较小的解。

这个是损失函数

Pooling的作用：

1. **降低计算量**

特征图尺寸变小，后续卷积层需要处理的数据更少。

2. **扩大有效感受野**

后续网络中的一个神经元可以对应原图中更大的区域，更容易学习整体结构。

3. **增强一定的平移鲁棒性**

如果目标在局部位置发生小幅移动，池化后的结果可能仍然相近。

4. **保留主要特征，减少细节噪声**

池化会聚合一个局部区域的信息，对局部微小变化不那么敏感。

5. **减少过拟合风险**

特征图空间尺寸变小，模型可学习的细节减少，因此可能具有一定正则化效果。

## batch normalization

最上层，最靠近输出层的位置，梯度越大，因为反向传播，越靠近输入层，梯度越小。

上层会很快收敛，下层收敛慢。底层一变动，所有都得跟着变。最后的那些层需要重新学习很多次。导致收敛变慢。

**批量归一化**

固定小批量里面的均值和方差。先将均值方差变为0，1。

R和B是全局共享的不会发生变化。

![image-20260427161103080](images/image-20260427161103080.png)

可学习的参数为r和b

作用在卷积和全连接层与激活函数之间

对于全连接层，作用在特征维度。（对每一个全连接做一次数据预处理）

对于卷积层，作用在通道维度（对每一个像素）（样本数是批量大小和高宽）（通道相同位置的像素做归一化）

**批量归一化在做什么**

通过在每个小批量里加入噪音来控制模型复杂度。

可以加速收敛，很少改变精度。

**在全连接层中，输入数据的维度通常是二维：`[B, D]`。**

FC 层中的归一化是**针对每一个神经元（每一个特征维度）独立进行的**。 也就是说，如果有 $D$ 个特征，BN 会计算 $D$ 组不同的均值和方差，分别对每个特征在当前 Batch（大小为 $B$）内的样本数据求平均和方差。

**在卷积层中，特征图（Feature Map）的数据维度通常是四维：`[B, C, H, W]`（以 PyTorch 维度排列为例）。**

卷积层有一个极重要的物理假设——**权值共享（Weight Sharing）**。同一个通道（Channel）上的所有像素点都是由同一个卷积核提取出来的特征。

因此，卷积 BN 的归一化是**按通道（Channel）划分**的。对于第 $c$ 个通道，BN 不仅跨 Batch（$B$ 个样本），还同时跨越所有空间位置（$H \times W$ 个像素点）来统一计算均值和方差。

相当于把 $B \times H \times W$ 个标量值当成同一个特征分布下的样本，共计算出 $C$ 组均值和方差。

## ResNet

加入更多的层并不一定改变精度。

![image-20260427171858204](images/image-20260427171858204.png)

![image-20260427172021181](images/image-20260427172021181.png)

残差快使得更深的网络更容易训练

从梯度大小来解释，因为加入了x，所以梯度不会特别小

**核心创新：残差连接（Skip Connection**

ResNet 的解决思路非常巧妙：**既然直接学习理想的目标映射 $F(x)$ 很困难，不如改学“残差” $F(x) = H(x) - x$。**

- **传统网络**：让网络层直接去拟合目标输出 $H(x)$。
- **残差网络**：把网络结构设计为 $H(x) = F(x) + x$。

它通过一条**短路连接（Skip Connection / Shortcut）**，把输入 $x$ 直接跨层加到输出上：

### 为什么这个设计有效？

1. **梯度传导的“高速公路”**：在前向传播时，信息可以直接穿过；在反向传播计算梯度时，梯度可以通过短路路径无损地传回浅层，**极大地缓解了梯度消失问题**。
2. **极低的保底风险**：如果某些深层卷积层学不到有用特征，网络只需把这几层的参数调整为 0，即 $F(x) = 0$，整体就退化为一个普通的“恒等映射” $H(x) = x$，至少不会比浅层网络表现更差。

**传统网络（一次性到位）：**

每一层都试图直接去拟合最终的目标特征 $H(x)$。越往深层走，网络背负的负担越重，一旦前面的层没学好，后面的层就很容易“走火入魔”或产生梯度消失。

**ResNet（逐层打补丁）：**

它把任务拆解了。因为有了跳跃连接（Skip Connection），输入 $x$ 可以原封不动地传过去。

- **第一层/前几层**：先建立一个基础模型（初步拟合），输出 $x$。
- **后续的残差块**：只需要学习当前输出和目标之间的**差距（残差 $F(x)$）**。

## 锚框

---------

算法对边框位置的猜测

IOU--交并比

用来表示两个框的相似度

0表示无重合，1表示完全重合。

锚框（Anchor Box）是目标检测中预先设定的一组候选矩形框，用来表示不同位置、尺寸和宽高比的潜在目标。

模型通常会：

1. 在图像网格的每个位置生成多个锚框；
2. 判断每个锚框里是否有目标；
3. 预测目标类别；
4. 调整锚框的位置和大小，使其贴合真实目标。

例如，在检测行人时，可以预设“窄而高”的锚框；检测汽车时，可以预设“宽而矮”的锚框。

Faster R-CNN、SSD 等经典检测器大量使用锚框。较新的 YOLO 系列部分版本采用无锚框（anchor-free）方法，直接预测目标中心点和边界框。

**训练时每一个锚框是一个训练样本。**

- 一个锚框要么背景，要么关联一个真实框。
- 我们可能生产大量的锚框，这会导致大量的负类样本。

**以每个像素为中心，生成多个缩放比和宽高比（aspect ratio）不同的边界框。 这些边界框被称为*锚框*（anchor box）。**

假设输入图像的高度为ℎ，宽度为w。 我们以图像的每个像素为中心生成不同形状的锚框：*缩放比*为s∈(0,1]，*宽高比*为r>0。 那么锚框的宽度和高度分别是![hs\sqrt{r}](https://latex.csdn.net/eq?hs%5Csqrt%7Br%7D)和![hs/\sqrt{r}](https://latex.csdn.net/eq?hs/%5Csqrt%7Br%7D)。 要生成多个不同形状的锚框，让我们设置许多缩放比（scale）取值![r_1](https://latex.csdn.net/eq?r_1),…,![r_n](https://latex.csdn.net/eq?r_n)和许多宽高比。（aspect ratio）取值![s_1](https://latex.csdn.net/eq?s_1),…,![s_n](https://latex.csdn.net/eq?s_n)。 当使用这些比例和长宽比的所有组合以每个像素为中心时，输入图像将总共有![w*h*n*m](https://latex.csdn.net/eq?w*h*n*m)个锚框。

以同一像素为中心的锚框的数量是![n+m-1](https://latex.csdn.net/eq?n&plus;m-1)。 对于整个输入图像，将共生成![wh(n+m-1)](https://latex.csdn.net/eq?wh%28n&plus;m-1%29)个锚框。

**将真实边界框分配给锚框 **

 在训练集中，我们将每个锚框视为一个训练样本。**我们需要每个锚框的*类别*（class）和*偏移量*（offset）标签**，其中前者是与锚框相关的对象的类别，后者是真实边界框相对于锚框的偏移量。在预测时，**我们为每个图像生成多个锚框，预测所有锚框的类别和偏移量**，根据预测的偏移量调整它们的位置以获得预测的边界框，最后只输出符合特定条件的预测边界框。

给定图像，假设锚框是A，真实边界框是B。 让我们定义一个矩阵∈，其中第行、第列的元素是锚框和真实边界框的IoU。 该算法包含以下步骤。

在矩阵中找到最大的元素，并将它的行索引和列索引分别表示为和。然后将真实边界框分配给锚框。这很直观，因为和是所有锚框和真实边界框配对中最相近的。在第一个分配完成后，丢弃矩阵中行和列中的所有元素。

在矩阵中找到剩余元素中最大的元素，并将它的行索引和列索引分别表示为和。我们将真实边界框分配给锚框，并丢弃矩阵中行和列中的所有元素。

此时，矩阵中两行和两列中的元素已被丢弃。我们继续，直到丢弃掉矩阵中列中的所有元素。**此时已经为这个锚框各自分配了一个真实边界框。**

只遍历剩下的−个锚框。例如，给定任何锚框，在矩阵的第行中找到与的IoU最大的真实边界框，**只有当此IoU大于预定义的阈值时，才将分配给。**
![image-20260506162418021](images/image-20260506162418021.png)



使用非极大值抑制输出

   其基本原理是先在图像中找到所有可能包含目标物体的矩形区域，**并按照它们的置信度进行排列。**然后从置信度最高的矩形开始，遍历所有的矩形，如果发现当前的矩形与前面任意一个矩形的重叠面积大于一个阈值，则将当前矩形舍去。使得最终保留的预测框数量最少，**但同时又能够保证检测的准确性和召回率**。

1. 对于每个类别，按照预测框的置信度进行排序，**将置信度最高的预测框作为基准。**
2. 从剩余的预测框中选择一个与基准框的重叠面积最大的框，**如果其重叠面积大于一定的阈值，则将其删除。**
3. 对于剩余的预测框，重复步骤2，直到所有的重叠面积都小于阈值，或者没有被删除的框剩余为止。

值得注意的是，NMS的阈值通常需要根据具体的数据集和应用场景进行调整，以兼顾**准确性和召回率**。



## 物体检测 RCNN 

--------

在目标检测中，两阶段检测和单阶段检测的核心区别是：**是否先生成候选区域，再进行分类和定位**。

```cmd
输入图像
  → 生成候选区域（Region Proposals）
  → 对候选区域进行分类
  → 精修边界框
  → 检测结果
  
  
  
  输入图像
  → 神经网络直接预测类别和边界框
  → 检测结果
```

可以简单理解为：

- **两阶段检测**：先问“哪里可能有目标”，再问“它是什么”。**先生成候选区域。**
- **单阶段检测**：一次性回答“哪里有什么目标”。

**RCNN**（Region-based Convolutional Neural Networks）是一种经典的目标检测算法，最初由Girshick等人在2014年提出。它通过将图像分割成多个候选区域，并对每个候选区域进行分类和边界框回归来实现目标检测。

1. 候选区域（Region Proposals）生成：在图像中提取候选区域，这些候选区域通常是通过**选择性搜索（Selective**
   **Search）等算法生成的**。选择性搜索将图像分割为多个不同尺度和形状的区域，并根据颜色、纹理、大小等特征进行合并，以产生可能包含目标的候选区域。
2. 特征提取：对每个候选区域应用卷积神经网络（CNN）来提取特征表示。通常使用预训练的CNN模型，如AlexNet、VGGNet或ResNet等，在候选区域上进行前向传播，以获得固定长度的特征向量。
3. 目标分类:提取的特征向量作为输入，经过一个支持向量机（Support Vector Machine，SVM）分类器进行目标类别的分类。在训练阶段，SVM使用正负样本对模型进行训练，学习区分目标和非目标的能力。
4. 非极大值抑制：由于选择性搜索算法可能会生成重叠的候选区域，为了消除冗余的检测结果，R-CNN使用非极大值抑制（Non-Maximum Suppression，NMS）来筛选最终的检测边界框。NMS通过比较检测框之间的重叠程度和得分，并保留最具有代表性的框。

#### 候选区域生成

Selective Search：训练过程中用于从输入图像中搜索出2000个Region Proposal。主要步骤：

使用一种过分割手段，将图像分割成小区域 (1k~2k 个)
计算所有邻近区域之间的相似性，包括颜色、纹理、尺度等
将相似度比较高的区域合并到一起
计算合并区域和临近区域的相似度
重复3、4过程，直到整个图片变成一个区域
在每次迭代中，形成更大的区域并将其添加到区域提议列表中。这种自下而上的方式可以创建从小到大的不同scale的Region Proposal，如图所示:

#### 特征提取

RCNN由四个部分组成：SS算法、CNN、SVM、bbox regression。

**网络架构选择**

两个可选方案：第一选择经典的Alexnet；第二选择VGG16

有监督预训练阶段(训练网络参数)
在实际测试的时候，模型需要通过CNN提取出中的特征，用于后面的分类与回归。所以，如何训练好CNN成为重中之重。

在原始 R-CNN（Regions with CNN features）论文中，由于目标检测数据集（如 PASCAL VOC）规模较小，直接从头训练深度卷积网络（如 AlexNet）会导致严重过拟合。

因此，R-CNN 提出了著名的“两阶段训练策略”**：先在超大规模分类数据集上进行**监督预训练，再在目标检测数据集上针对候选区域（Region Proposals）进行**特定领域微调**。

由于物体标签训练数据少，如果要直接采用随机初始化CNN参数的方法,目前的训练数据量是不够的. 基于此，采用有监督的预训练，使用一个大的数据集（ImageNet )来训练AlexNet，得到一个1000分类的预训练（Pre-trained）模型。网络优化求解时采用随机梯度下降法（SGD），学习率大小为0.001.

预训练完成后，网络需要适应目标检测任务（处理变形裁剪后的局部区域，并适应目标类别）。

**网络结构改造与替换**

将 ImageNet 预训练模型的最后一个 1000 维分类全连接层（Softmax 层）裁掉。

替换为一个全新的 **$(N + 1)$ 维全连接层**（其中 $N$ 是检测数据集的真实目标类别数，加上 1 个背景类）。

新全连接层的权重进行随机初始化，其余卷积层和全连接层保留预训练权重。

**候选区域预处理（Warping）**

使用选择性搜索（Selective Search）算法从每张训练图像中提取约 2000 个候选区域（Region Proposals）。

不管候选区域原本的长宽比如何，**一律各向异性缩放/变形（Warping）强制转换为 CNN 输入所需的固定尺寸**（例如 AlexNet 要求 $227 \times 227$ 像素）。

**划分正负样本（正负样本采样）**

为了计算分类 Loss，需要给这 2000 个候选框打上类别标签：

- **正样本（Positive Samples）**：与任意真实标注框（Ground Truth）的 **$\text{IoU} \ge 0.5$** 的候选框。其类别标记为该真实目标的类别。
- **负样本（Negative Samples）**：与所有真实标注框的 **$\text{IoU} < 0.5$** 的候选框。其类别统一标记为**背景（Background, 类 0）**。

**端到端微调训练**

**Batch 构建**：每个 Mini-batch 包含 **128 个候选框**（由 32 个正样本框和 96 个背景负样本框组合而成，正负比例为 $1:3$），这种设计避免了背景过多导致的样本倾斜。

**超参数与优化器**：使用带冲量的 SGD（Stochastic Gradient Descent）。由于网络大部分权重已经收敛，学习率设置得很小（初始学习率 $\eta = 0.001$，为预训练时的 $1/10$），防止破坏预训练特征。

**总结**：RCNN训练流程复杂，候选区域生成不精确，计算资源消耗大。





### Fast RCNN

![image-20260506202133268](images/image-20260506202133268.png)

Fast R-CNN主要是为了解决R-CNN的以下几个问题：

**训练分多步**：R-CNN的训练先要fine tuning（微调）一个预训练的网络，然后针对每个类别都训练一个SVM分类器，最后还要训练一个线性回归模型对bounding-box进行回归。
**时间和内存消耗比较大**。

#### FastRCNN的改进
**共享卷积计算：整张图只需过一次 CNN（最核心优化**

- **原始 R-CNN 的瓶颈**：先提取约 2000 个候选区域（Region Proposals），再将**每个候选区域独立输入** CNN 前向传播，导致一张图要跑 2000 次重叠的卷积计算，极其耗时。
- **Fast R-CNN 的改进**：将**整张原图一次性输入** CNN 提取特征图（Feature Map）。同时，将 Selective Search 提取的候选框映射到特征图对应的位置上。**重叠区域的卷积特征只需要计算一次**，大幅消除了冗余计算。

**引入 RoI Pooling（感兴趣区域池化）**
由于不同候选框的长宽比和尺寸各不相同，**而全连接层（FC Layer）要求固定维度的输入**，Fast R-CNN 提出了 RoI Pooling 层：运作原理：**将特征图上任意大小的候选区域（RoI）网格化划分为 $H \times W$（通常为 $7 \times 7$）个相等的子区域（Bins）**，在每个子区域内执行 **Max Pooling**。效果：无论输入的候选框多大或比例如何，经过 RoI Pooling 都可以输出固定尺寸（$7 \times 7 \times C$）的特征向量，彻底取代了 R-CNN 原本对图像裁剪变形（Warping）的做法。

**端到端多任务联合训练（End-to-End Multi-task Training**

- **原始 R-CNN 的繁琐**：训练分为三步——微调 CNN、训练独立的 SVM 分类器、训练独立的线性回归器。三者无法联动且需要保存特征到磁盘。
- **Fast R-CNN 的改进**：摒弃了 SVM 和独立的脊回归器，在 RoI Pooling 和全连接层之后分支为**两个并行的输出头**：
  1. **分类头（Softmax Head）**：输出 $K+1$ 个类别的概率分布。
  2. **回归头（Bounding Box Regressor Head）**：输出 $K+1$ 组平移与缩放偏移量 $(t_x, t_y, t_w, t_h)$。

同时，设计了**多任务联合损失函数（Multi-task Loss）**，让分类和定位在一个网络中联合优化、端到端反向传播：
$$
L(p, u, t^u, v) = L_{\text{cls}}(p, u) + \lambda \cdot [u \ge 1] \cdot L_{\text{loc}}(t^u, v)
$$




**Fast RCNN算法流程**

1. 一张图像生成1K~2K个候选区域(使用Selective Search算法，简称SS算法)，我们将某个候选区域称为ROI区域。
2. 将图像输入网络得到相应的特征图，将SS算法生成的候选框投影到特征图上获得相应的特征矩阵。

3. 将每个特征矩阵通过 ROI pooling 层缩放到7×7大小的特征图。

Fast R-CNN 的特征提取层输出是整张图像的**共享卷积特征图**（feature map），随后，每个候选区域 RoI 会映射到这张特征图上，经过 **RoI Pooling** 得到固定大小的特征形状通常为：\(512 \times 7 \times 7\)

**Faster-RCNN**

Faster R-CNN 相比 Fast R-CNN 的核心改进是：**用可训练的 RPN 替代 Selective Search 来生成候选区域**。将候选框生成也融入到CNN网络中，使得 候选框生成、特征提取、候选框分类、候选框边界回归这四大部分都结合在一个CNN网络中，避免了分步训练，实现了真正**端到端**的目标检测。



**算法流程：**

- 将图像输入CNN网络得到相应的特征图。
- 使用**RPN网络**生成候选框，将RPN生成的候选框投影到特征图上获得ROI区域的特征矩阵。
- 将每个ROI区域的特征矩阵通过 ROI pooling层缩放到7×7大小的特征图，接着将特征图展平为vector，之后通过一系列全连接层得到预测结果。

**RPN网络结构**

anchor不是候选框（Proposal），后面会提到二者的区别。

比起锚框候选框的选择要参考图像的构成，而锚框更像随手画的圈。

RPN（Region Proposal Network）生成候选框的过程，可以理解为：**先大量提出初始猜测，再结合图像特征修正、打分和筛选。**

**RPN 本质上就是一个轻量级、类别无关的目标检测网络**。

它与普通目标检测网络一样，也有两个输出头：主要区别是，**RPN 不负责判断物体的具体类别。**

RPN 在特征图上滑动，并在每个空间位置对对应的锚框预：

- **Objectness 分数**：该锚框是前景还是背景
- **边界框偏移量**：怎样调整锚框的位置与大小

同时，这张特征图也会交给后续检测头使用：

### Mask RCNN

Mask R-CNN是一个非常灵活的框架，可以增加不同的分支完成不同的任务，可以完成目标分类、目标检测、语义分割、实例分割、人体姿势识别等多种任务。

Mask-RCNN 大体框架还是 Faster-RCNN 的框架，可以说在基础特征网络之后又加入了全连接的分割子网，由原来的两个任务（分类+回归）变为了三个任务（分类+回归+分割）。Mask R-CNN 采用和Faster R-CNN相同的两个阶段:

第一个阶段具有相同的第一层(即RPN)，扫描图像并生成候选框（proposals，即有可能包含一个目标的区域）;

第二阶段，除了预测种类和bbox回归，并添加了一个全卷积网络的分支，对每个RoI预测了对应的二值掩膜(binary mask)，以说明给定像素是否是目标的一部分。所谓二进制mask，就是当像素属于目标的所有位置上时标识为1，其它位置标识为 0。
**Mask R-CNN 在 Faster R-CNN 的基础上新增了一个掩码预测头（Mask Head）**，另外，Mask R-CNN 用 **RoI Align** 替代了 RoI Pooling，避免坐标取整造成的空间错位。

### YOLOV2

YOLOv2（发表于 2017 年论文《YOLO9000: Better, Faster, Stronger》）针对 YOLOv1 **定位不准（Recall 偏低）** 和 **召回率低** 的痛点，从**精度（Better）**、**速度（Faster）** 和 **识别种类（Stronger）** 三个维度进行了全面升级。

引入锚框，有了预定义长宽的框。

### 1. 引入批归一化（Batch Normalization

在每个卷积层后加入 Batch Normalization（BN），加速收敛的同时起到正则化作用。  

### 2.高分辨率分类器预训练（High Resolution Classifier）  

YOLOv1 是在 $224 \times 224$ 的分辨率下预训练分类网络，然后再切到 $448 \times 448$ 训练检测网络，网络需要同时适应分辨率变化和检测任务。

### 3.基于 Anchor Boxes 的全卷积预测

取消了 YOLOv1 结尾的全连接层（FC 层），全面采用全卷积网络（FCN），并引入类似 Faster R-CNN 的 **Anchor Box（先验框）** 机制。

YOLOv2作者发现通过预测偏移量而不是坐标值能够简化问题，让神经网络学习起来更容易。借鉴Faster RCNN的做法，YOLOv2也尝试采用先验框（anchor）。在每个grid预先设定一组不同大小和宽高比的边框，来覆盖整个图像的不同位置和多种尺度。最终YOLOv2去掉了全连接层，使用Anchor Boxes来预测 Bounding Boxes。作者去掉了网络中一个Pooling层，这让卷积层的输出能有更高的分辨率。

### 4. 聚类提取先验框维度（Dimension Clusters）

不同于 Faster R-CNN 手动（Hand-picked）预设 Anchor 的长宽比，YOLOv2 使用 **K-Means 聚类算法** 在训练集边界框上自动寻找最佳的先验框尺寸。

### 5. 绝对位置直接预测（Direct Location Prediction）

 **YOLOv2 如何解决“引入 Anchor Box 后模型训练容易不稳定”的问题**，也是 YOLO 架构中最经典的创新之一：**直接位置预测（Direct Location Prediction）**。

为了让你彻底搞懂，我们可以把它拆解为 **“背景痛点”**、**“解法逻辑”** 和 **“公式拆解”** 三个部分：

### 1. 背景与痛点：为什么 Anchor Box 会让训练不稳定？

传统的 Faster R-CNN 等模型在使用 Anchor Box 时，网络预测的是目标中心点 $(x, y)$ 相对于 Anchor 中心点的**无界偏移量**（Unbounded Offset）。

- **问题在于：** 如果网络输出的预测值 $t_x$ 或 $t_y$ 很大（比如预测了 $+10$ 或 $-5$），预测出来的框就会**飞到距离当前网格非常远的地方**。
- **后果：** 在训练刚开始（初始化阶段），网络权重未收敛，预测值容易出现巨大的随机波动，导致预测框满屏幕乱飞。这需要很长时间才能稳定下来，甚至会导致梯度爆炸。

### 2. YOLOv2 的解法：给中心点预测加上“硬性约束”

YOLO 的核心原则是：**哪个网格（Grid Cell）负责预测目标，目标的中心点就必须落在该网格内部！**

为了强行把中心点限制在当前网格（网格边长定义为 1）里，YOLOv2 做了两件事：

1. 网络不预测相对于 Anchor 的无限制偏移，而是预测相对于**当前网格左上角**的**相对偏移量**。
2. 使用 **Logistic Sigmoid 函数 $\sigma(\cdot)$** 处理网络预测的 $t_x, t_y$。
   - Sigmoid 函数的物理特性是：无论输入的实数多大或多小，输出永远被“压缩”在 **$(0, 1)$ 之间**。

### 3. 图解与公式逐项拆解

结合你提供的图片，我们来拆解这 5 个公式（右侧公式）：

#### ① 中心点坐标 $(b_x, b_y)$ 的计算：

$$b_x = \sigma(t_x) + c_x$$

$$b_y = \sigma(t_y) + c_y$$

- **$c_x, c_y$：** 当前网格**左上角**在整张图片中的网格坐标（例如图中左上角的第 $(1, 1)$ 或 $(2, 2)$ 个格子）。
- **$t_x, t_y$：** 网络直接预测出来的原始数值（任意实数）。
- **$\sigma(t_x), \sigma(t_y)$：** 经过 Sigmoid 激活后的结果，**严格介于 $0$ 到 $1$ 之间**。
- **物理意义：** $\sigma(t_x)$ 代表中心点距离当前网格左边界的相对距离；$\sigma(t_y)$ 代表距离上边界的相对距离。加上 $c_x, c_y$ 相当于把中心点精准定位在图像上的全局位置。**因为 $\sigma(t) \in (0, 1)$，中心点被锁死在当前网格内，绝对不会乱跑！**

#### ② 框的宽高 $(b_w, b_h)$ 的计算：

$$b_w = p_w \cdot e^{t_w}$$

$$b_h = p_h \cdot e^{t_h}$$

- **$p_w, p_h$：** 预先通过 K-Means 聚类得到的 Anchor Box（图中的虚线框 Bounding Box Prior）的宽高。
- **$t_w, t_h$：** 网络预测的宽高缩放系数（原始数值）。
- **$e^{t_w}, e^{t_h}$：** 通过指数函数 $\exp$ 确保缩放比例恒大于 0。
- **物理意义：** 模型以 Anchor 的宽高为基准，做乘法缩放得到最终预测框（图中的蓝色实线框）的宽高。

#### ③ 置信度（Confidence Score）的计算：

$$\text{Pr}(\text{object}) \times \text{IOU}(b, \text{object}) = \sigma(t_o)$$

- **$t_o$：** 网络预测的原始置信度得分。
- **$\sigma(t_o)$：** 同样用 Sigmoid 函数压缩到 $[0, 1]$ 之间，代表“这个框里**有目标的概率**”乘以“预测框与真实框的 **IoU**”。

### 总结一句话

这段话的核心精髓是：**通过引入 Sigmoid 函数 $\sigma(\cdot)$，YOLOv2 将网络预测的中心点坐标强行限制在当前网格的范围 $(0, 1)$ 之内。这样既保留了 Anchor 预测长宽的优势，又彻底解决了训练初期预测框“满屏乱飞”导致模型不稳定的问题。**

### 6. 细粒度特征融合（Fine-Grained Features / Passthrough Layer）  

$13 \times 13$ 的特征图对于检测小物体较弱。

- **改进**：引入 **Passthrough 层**，将前面高分辨率的 $26 \times 26 \times 512$ 特征图进行拆分重排（拆成 4 个 $13 \times 13 \times 512$ 并叠加为 $13 \times 13 \times 2048$），再与深层的 $13 \times 13 \times 1024$ 特征图跨通道拼接（Concat）。

### 7. 多尺度训练（Multi-Scale Training）  

因为移除了全连接层，网络支持动态输入尺寸。

- **机制**：训练过程中，每迭代 10 个 batch，网络就会在 $\{320, 352, \dots, 608\}$（步长 32 的随机尺寸）中随机选取一个新的输入图像尺寸。  

在 YOLOv1 中，网络的末端使用了**全连接层（Fully Connected Layers）**。全连接层对输入的尺寸有固定的硬性要求，导致 YOLOv1 只能接收固定大小（$448 \times 448$）的图片输入。

YOLOv2 将网络主干更换为自研的 **Darknet-19**，并彻底取消了所有的全连接层，改用纯粹的**全卷积网络（FCN）**

当输入图像分辨率变化时，最终预测特征图的大小按 $1/32$ 比例同步缩放：

- **$320 \times 320$** 输入 $\rightarrow$ 最终特征图大小为 **$10 \times 10$**
- **$416 \times 416$** 输入 $\rightarrow$ 最终特征图大小为 **$13 \times 13$**（标准分辨率）
- **$608 \times 608$** 输入 $\rightarrow$ 最终特征图大小为 **$19 \times 19$**

>
> 因为 YOLO 是一种**完全基于网格（Grid）的无全连接密集预测网络**。
>
> - $13 \times 13$ 的特征图意味着将图像划分成了 $13 \times 13$ 个网格，每个网格预测 $B$ 个 Bounding Box；

特征提取部分采用**Darknet-53**网络结构代替原来的Darknet-19，利用特征金字塔网络**FPN**结构实现了多尺度检测，分类方法使用**逻辑回归代替了softmax**，在兼顾实用性的同时保证了目标检测的准确性。

相比于 YOLOv2 的 骨干网络，YOLOv3 进行了较大的改进。借助残差网络的思想，YOLOv3 将原来的 darknet-19 改进为darknet-53。论文中给出的整体结构如下：

卷积层、BN层以及LeakyReLU共同组成Darknet-53的基本CBL。因为在Darknet-53中共包含53个这样的CBL，所以称其为Darkent-53。

为了更加清晰地了解Darknet-53的网络结构，可以看下面这张图：

![img](images/ea397d58aa167d13cd71ddd4f63c9cc9.png)



为了更好的理解此图，下面对主要单元进行说明：

CBL：一个卷积层、一个BN层和一个Leaky ReLU组成的基本卷积单元。
res unit：输入通过两个CBL后，再与原输入进行add；这是一种常规的残差单元。残差单元的目的是为了让网络可以提取到更深层的特征，同时避免出现梯度消失或爆炸。
ResX：X个残差组件。
concat：将Darknet-53的中间层和后面的某一层的上采样进行张量拼接，达到多尺度特征融合的目的。这与残差层的add操作是不一样的，拼接会扩充张量的维度，而add直接相加不会导致张量维度的改变。
最后面的蓝色立方体表示三种尺度的输出。

YOLOv3 的特征融合借鉴了 **FPN（Feature Pyramid Network，特征金字塔网络）** 的思想，核心机制是：**将深层网络的高阶语义信息通过上采样传递给浅层网络，并与浅层网络的高分辨率细节信息进行拼接（Concatenation）**。

### 1. 关键前提：3 个不同分辨率的输出层

在主干网络 Darknet-53 下采样的过程中，YOLOv3 抽取了 3 个不同深度的特征图（假设输入图像尺寸为 $416 \times 416$）：

- **Feature Map 1（深层/小尺寸）**：经过 32 倍下采样，尺寸为 **$13 \times 13$**。
- **Feature Map 2（中层/中尺寸）**：经过 16 倍下采样，尺寸为 **$26 \times 26$**。
- **Feature Map 3（浅层/大尺寸）**：经过 8 倍下采样，尺寸为 **$52 \times 52$**。

### 2. 特征融合的具体步骤（自顶向下）

YOLOv3 采用自顶向下（从深层到浅层）的特征融合路径，分为以下两个阶段：

```
深层特征图 (13x13) ───[卷积提取]───────> [输出预测 1 (针对大目标)]
                             │
                        [2倍上采样]
                             │
                             ▼
中层特征图 (26x26) ───[Concat 拼接]───> [输出预测 2 (针对中目标)]
                             │
                        [2倍上采样]
                             │
                             ▼
浅层特征图 (52x52) ───[Concat 拼接]───> [输出预测 3 (针对小目标)]
```

### 3. 为什么选择 Concat（通道拼接）而不是 Add（按位相加）？

在卷积神经网络中，特征融合主要有两种手段：

- **Add（加法融合，如 ResNet）**：对应位置上的数值直接相加，**通道数不变**。
- **Concat（拼接融合，如 DenseNet / YOLOv3）**：直接将多个特征图在通道维度堆叠，**通道数增加**（例如 256 通道与 512 通道拼接后变成 768 通道）。

**YOLOv3 选择 Concat 的理由：**

- **信息互补而不冲淡**：深层特征偏重于“**这个东西是什么**”（语义信息），浅层特征偏重于“**这个东西在哪里/轮廓长怎样**”（位置细节）。两者属于完全不同维度的信息，**Concat 能把两者的信息完整保留**，由后续的 $1 \times 1$ 和 $3 \times 3$ 卷积层自主学习如何组合与权重分配。

这种设计大幅提升了模型对多尺度目标的感知能力，特别是让小目标（在 $52 \times 52$ 融合特征图上预测）借用到了深层网路传来的丰富语义，从而解决了 YOLOv1/v2 时代最棘手的小目标漏检问题。

###  先验框（Anchor Boxes）重新聚类

YOLOv3 延续了 YOLOv2 引入的 Anchor 机制，但将每种尺度下分配的候选框进行了精细化更新：

- 使用 **K-Means 聚类算法** 在 COCO 数据集上重新聚类出 **9 种不同尺度的 Anchor**。  
- **分配方式**：按大小分配到 3 个预测特征图上，每个特征图负责 3 个 Anchor。  
  - 大尺度特征图 $\rightarrow$ 小 Anchor（针对小目标）
  - 中尺度特征图 $\rightarrow$ 中 Anchor
  - 小尺度特征图 $\rightarrow$ 大 Anchor（针对大目标）

### 分类器升级：用 Logistic 回归取代 Softmax

- **多标签分类（Multi-label Classification）**：在真实场景中，类别标签往往不是互斥的（例如，同一个目标可以同时被标记为“女人”和“人”）。
- YOLOv3 **放弃了单标签互斥的 Softmax 分类器**，改用多个独立的 **Logistic 回归二分类器**（通过 Binary Cross-Entropy 损失函数训练）。这使得模型能够更好地应对复杂场景和重叠类别的预测。  

**Softmax 输出的确实是一个长度为 $n$ 的向量，但它代表的是“单标签互斥分类”，而不是真正意义上的“多标签分类”。**

主要区别在于 **概率的约束规则** 以及 **它假设类别之间是否互斥**。

**1. 为什么 Softmax 不是多标签分类？**

Softmax 函数的数学定义为：

$$
P(y = i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}
$$

观察它的分母会发现，Softmax 会把所有 $n$ 个类别的原始得分（Logits）**进行归一化，使得所有类别的概率加起来必须等于 1**：

$$
\sum_{i=1}^{n} P(y = i) = 1
$$

#### 这带来的后果是“零和博弈”（互斥性）：

- **一个类别概率变大，其他类别的概率就会被挤压变小。**
- 这种机制强迫模型做出**排他性选择**：假设输出向量是 $[0.8, 0.1, 0.1]$，它表达的意思是“这个目标有 80% 的概率是人，10% 是狗，10% 是车”，**模型默认这个目标只能是其中一种**。

### **FPN（Feature Pyramid Network，特征金字塔网络）** 

是目标检测领域最经典、最重要的结构创新之一，由 Tsung-Yi Lin 等人在 CVPR 2017 论文中提出。

它的核心目的，是为了解决传统卷积神经网络（CNN）在**检测小目标（Small Objects）时效果极差**的痛点。

### 1. 为什么需要 FPN？（背景与痛点）

在经典的深度卷积神经网络中，越往深层网络走，下采样（如 Pooling 或带步长的卷积）次数越多：

- **浅层特征图（高分辨率、低语义）**：空间分辨率大，能保留细粒度的位置信息（边缘、轮廓），非常**适合定位小目标**；但由于网络层数浅，缺乏全局上下文，**特征语义信息弱**，容易认错类别。
- **深层特征图（低分辨率、高语义）**：感受野大，经过多层抽象后具备极强的语义辨识能力（知道“这是什么”），**适合分类和大目标检测**；但空间分辨率大幅缩小，小目标的特征信息在多次下采样中**几乎丢失殆尽**（可能只剩 1x1 甚至被抹去）。

传统的解决方案要么只用最后一层特征图做检测（对小目标极其不友好），要么对不同尺度的图像做图像金字塔（计算成本极高）。

**FPN 的设计理念就是：既要深层强大的“语义信息”，又要浅层丰富的“空间分辨率”，而且计算成本还要低！**

### 2. FPN 的核心架构与原理

FPN 的结构可以概括为三个核心部分：**自下而上（Bottom-up）、自上而下（Top-down）与横向连接（Lateral Connections）**。

```
          自下而上 (主干网络)                自上而下 (特征融合)          预测层
[深层]     Conv5 (小尺寸/强语义) ─── 1x1 卷积 ────> P5 (13x13) ────────> 检测大目标
                                                  │
                                               2倍上采样
                                                  │
                                                  ▼  (+) Concat/Add
[中层]     Conv4 (中尺寸/中语义) ─── 1x1 卷积 ────> P4 (26x26) ────────> 检测中目标
                                                  │
                                               2倍上采样
                                                  │
                                                  ▼  (+) Concat/Add
[浅层]     Conv3 (大尺寸/弱语义) ─── 1x1 卷积 ────> P3 (52x52) ────────> 检测小目标
```

FPN 提出后，成为了后续几乎所有主流目标检测模型（Faster R-CNN、SSD、YOLO 系列等）的标配 Neck 结构，并衍生出了多个升级版本：

- **PANet（Path Aggregation Network，被 YOLOv4/v5 采纳）**：在 FPN 自上而下路径的基础上，引入了**自下而上的增强路径**，让浅层定位信息也能更高效地传给深层。
- **BiFPN（EfficientDet 提出）**：引入双向加权特征融合，跳过不必要的节点，极大地提高了特征融合的效率与精度。



### YOLOV4

其核心改进思路是：**在不增加推理成本的前提下极大提升检测精度，并确保模型可以在单张消费级 GPU（如 GTX 1080Ti / RTX 2080Ti）上高效训练**。

![img](images/ae18d778f29ab86da4ecf6ac9e051521.png)



先详细介绍一下YOLOv4的基本组件：

- CBM：Yolov4网络结构中的最小组件，由Conv+Bn+Mish激活函数三者组成。
- CBL：由Conv+Bn+Leaky_relu激活函数三者组成。
- Res unit：借鉴Resnet网络中的残差结构，让网络可以构建的更深。
- CSPX：借鉴CSPNet网络结构，由卷积层和X个Res unint模块Concate组成。
- SPP：采用1×1，5×5，9×9，13×13的最大池化的方式，进行多尺度融合。

  替换为 CBM 是为了利用 Mish 激活函数平滑、连续可微的特性，让深层主干网络提取到质量更高、更鲁棒的特征，同时避免梯度震荡，从而提升最终的检测精度。

**CSPNet（Cross Stage Partial Network，跨阶段局部网络）** 是由 Chien-Yao Wang（王建尧）等人于 2019 年提出的一种轻量级卷积神经网络架构设计思想。

它最初是为了解决深度神经网络在推理时**计算量过大、显存占用高、以及梯度信息重复**的问题。因为效果极其出色，CSPNet 被广泛应用于 YOLO 系列（如 YOLOv4、YOLOv5、YOLOv7、YOLOv8 等）的主干网络设计中。传统网络“废梯度”太多.CSPNet 的解决思路非常直接且巧妙：**“分而治之，跨阶段融合”**。

它在每个基础块（Stage / Block）的输入端，**将输入的特征图沿着通道（Channel）方向一分为二**：

**通道切分 (Part 1 & Part 2)**：

- **支路一（Main Branch）**：包含约 50% 的通道数，送入深层的卷积网络（如 ResNet Block / DenseBlock）进行复杂的特征提取。
- **支路二（Short-cut / Cross Stage Branch）**：包含剩下的 50% 通道，**绕过**复杂的卷积层，直接跨越当前阶段传导至末端。

在 Stage 的末端，将“提取完复杂特征的支路一”与“保持原貌的支路二”通过 **Concat（通道拼接）** 重新组合在一起。再通过一层 $1 \times 1$ 的卷积进行通道融合与下采样。消除了冗余梯度，保留了原始浅层特征，精度不仅没降低，反而显著上升。

**SPP（Spatial Pyramid Pooling，空间金字塔池化）** 最初由何恺明（Kaiming He）等人于 2014 年提出，旨在解决传统卷积神经网络（CNN）**必须输入固定尺寸图像**的限制。

在 YOLOv4 中使用的 **SPP 模块** 是经过改进的微型版本，其核心作用是**在几乎不增加计算量的前提下，大幅增大感受野并融合多尺度特征**。

**SPP 的诞生背景：解决“固定尺寸输入”问题**

传统的 CNN 模型（如 AlexNet、VGG）包含“卷积层 + 全连接层（FC）”。

- **卷积层**：对输入图像尺寸没有要求，可以接受任意大小的图像。
- **全连接层**：输入的向量长度必须是固定的（例如 $4096$）。

为了满足全连接层的固定输入要求，以往的做法是对输入图像进行**硬性裁剪（Crop）** 或 **变形缩放（Warp/Resize）**。但这会带来严重问题：特征图输入 SPP 模块后，会并行经过 **4 个不同尺度的最大池化（Max Pooling）路径**，然后将结果在通道维度上进行**拼接（Concat）**最终输出通道数变为原来的 4 倍，将四种不同感受野的特征聚合在了一起。

## 语言模型



给定文本序列，语言模型的目标是估计联合概率。
$$
p(x_1,x_2,......x_t)
$$
它的应用包括

- 做预训练模型（BERT,GPT-3）
- 给定前面几个词，生成后续文本





假设序列长度为2，我们预测
$$
p(x,x') = p(x)p(x'|x) =  \frac{n(x)}{n}\frac{n(x,x')}{n(x)}
$$
这里n是总词数，n(x)和 n(x,x')  是单个单纯和连续单词的出现次数

很容易扩展到长为3的情况：


$$
p(x,x_2,x_3) = p(x)p(x_2|x)p(x_3|x_2,x)
$$
**当序列很长时，因为文本量不够，很可能n(x1,x2,x3...xn) < 1**

使用马尔可夫假设可以缓解这个问题



一元语法：
$$
p(x1,x2,x3,x4) = p(x1)p(x2)p(x3)p(x4)
$$
二元语法
$$
p(x1,x2,x3,x4) = p(x1)p(x2|x1)p(x3|x2)p(x4|x3)
$$
三元语法
$$
p(x1,x2,x3,x4) = p(x1)p(x2|x1)p(x3|x2,x1)p(x4|x3,x2)
$$


不可能将任意长度的序列都保存下来，更多的时候使用二元语法。



随机采样--每次在原样本上采用一段长为t的序列，它后面那个就是预测值y。 文本预处理不同的是，每个token只用一次。



**如何随机生成一个小批量数据的特征和标签以供读取？**

１、文本序列可以是任意长的，因此任意长的序列可以被划分为具有**相同时间步数**的子序列

２、训练神经网络时，将这些具有相同步数的小批量子序列输入到模型中

- 假设神经网络一次处理具有　ｎ　个时间步的子序列

![img](https://i0.hdslb.com/bfs/note/02463b189b4ee4d30944abbc0d5fe63c2baffc50.png@990w_!web-note.webp)

- 上图展示了从原始文本序列中获得子序列的所有不同的方式，其中　ｎ　等于　５　，并且每个时间步的词元对应于一个字符

３、由于可以选择**任意偏移量**来指示初始位置，因此具有相当大的自由度

- 如果只选择一个偏移量，那么用于训练网络的、所有可能的子序列的覆盖范围将是有限的。因此可以从随机偏移量开始划分序列，来同时获得**覆盖性（ｃｏｖｅｒａｇｅ）**和**随机性（ｒａｎｄｏｍｎｅｓｓ）**





**随机采样（ｒａｎｄｏｍ　ｓａｍｐｌｉｎｇ）**

- 随机采样中，每个样本都是在原始的长序列上任意捕获的子序列
- 在迭代过程中，来自两个**相邻的、随机的、小批量中的**子序列不一定在原始序列上相邻
- 语言建模的目标是**基于当前所看到的词元预测下一个词元**，因此标签是**移位了一个词元**的原始序列





**顺序分区（sequential　ｐａｒｔｉｔｉｏｎｉｎｇ）**

- 顺序分区：迭代过程中，除了对原始序列可以随机抽样外，还可以**保证两个相邻的小批量中的子序列在原始序列上也是相邻的**，这种策略在基于小批量的迭代过程中**保留了拆分的子序列的顺序**

应用到语言模型中，循环神经网络根据当前词预测下一次时刻词。

通常使用困惑度（评价交叉熵）来衡量语言模型的好坏





让我们[**首先定义预测函数来生成`prefix`之后的新字符**]，

其中的`prefix`是一个用户提供的包含多个字符的字符串。

在循环遍历`prefix`中的开始字符时，

我们不断地将隐状态传递到下一个时间步，但是不生成任何输出。

这被称为**预热**（warm-up）期，

因为在此期间模型会自我更新（例如，更新隐状态），

但不会进行预测。

预热期结束后，隐状态的值通常比刚开始的初始值更适合预测，

从而预测字符并输出它们。



```PYTHON
def predict_ch8(prefix, num_preds, net, vocab, device):  #@save
    """在prefix后面生成新字符"""
    state = net.begin_state(batch_size=1, device=device)
    outputs = [vocab[prefix[0]]]
    get_input = lambda: torch.tensor([outputs[-1]], device=device).reshape((1, 1))
    for y in prefix[1:]:  # 预热期
        _, state = net(get_input(), state)
        outputs.append(vocab[y])
    for _ in range(num_preds):  # 预测num_preds步
        y, state = net(get_input(), state)
        outputs.append(int(y.argmax(dim=1).reshape(1)))
    return ''.join([vocab.idx_to_token[i] for i in outputs])
```

class Seq2SeqEncoder(d2l.Encoder):
    """用于序列到序列学习的循环神经网络编码器"""
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers,
                 dropout=0, **kwargs):
        super(Seq2SeqEncoder, self).__init__(**kwargs)
        # 嵌入层
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.GRU(embed_size, num_hiddens, num_layers,
                          dropout=dropout)

    def forward(self, X, *args):
        # 输出'X'的形状：(batch_size,num_steps,embed_size)
        X = self.embedding(X)
        # 在循环神经网络模型中，第一个轴对应于时间步
        X = X.permute(1, 0, 2)
        # 如果未提及状态，则默认为0
        output, state = self.rnn(X)
        # output的形状:(num_steps,batch_size,num_hiddens)
        # state的形状:(num_layers,batch_size,num_hiddens)
        return output, state

针对词向量有一个专门的层nn.Embedding，用来实现词与词向量的映射。

Embedding就是用一个低维稠密的向量表示一个对象，这里的对象可以是一个词（Word2vec ），也可以是一个物品（Item2vec），亦或是网络关系中的节点（Graph Embedding）。Embedding向量能够表达对象的某些特征，两个向量之间的距离反映了对象之间的相似性。简单的说，Embedding就是把一个东西映射到一个向量X。如果这个东西很像，那么得到的向量x1和x2的欧式距离很小。

Embedding的本质是信息的聚合和解耦，也就是信息的再表达。如下图所示，前一个是1x4的高维embedding，分别表示猫、狗、花、草四种属性值，后一个是1x2的低维embedding，分别表示动物、植物两种属性值。从高维embedding降维成低维embedding是信息的聚合，猫狗聚合成动物，花草聚合成植物；从低维embedding升维成高维embedding是信息的结构，动物解耦成猫狗，植物解耦成花草。

Embedding的另一个作用体现了：对低维数据进行升维时，可以把一些其他特征放大，或者把笼统的特征给分开。![在这里插入图片描述](images/2442d044478e5d3ef80b3846635cd33e.png)

class Seq2SeqDecoder(d2l.Decoder):
    """用于序列到序列学习的循环神经网络解码器"""
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers,
                 dropout=0, **kwargs):
        super(Seq2SeqDecoder, self).__init__(**kwargs)
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.GRU(embed_size + num_hiddens, num_hiddens, num_layers,
                          dropout=dropout)
        self.dense = nn.Linear(num_hiddens, vocab_size)

    def init_state(self, enc_outputs, *args):
        return enc_outputs[1]

    def forward(self, X, state):
        # 输出'X'的形状：(batch_size,num_steps,embed_size)
        X = self.embedding(X).permute(1, 0, 2)
        # 广播context，使其具有与X相同的num_steps
        context = state[-1].repeat(X.shape[0], 1, 1)
        X_and_context = torch.cat((X, context), 2)
        output, state = self.rnn(X_and_context, state)
        output = self.dense(output).permute(1, 0, 2)
        # output的形状:(batch_size,num_steps,vocab_size)
        # state的形状:(num_layers,batch_size,num_hiddens)
        return output, state
    
#decoder 有一个输出层
```

#@save
def sequence_mask(X, valid_len, value=0):
    """在序列中屏蔽不相关的项"""
    maxlen = X.size(1)
    mask = torch.arange((maxlen), dtype=torch.float32,
                        device=X.device)[None, :] < valid_len[:, None]
    X[~mask] = value
    return X

X = torch.tensor([[1, 2, 3], [4, 5, 6]])
sequence_mask(X, torch.tensor([1, 2]))

#@save
class MaskedSoftmaxCELoss(nn.CrossEntropyLoss):
    """带遮蔽的softmax交叉熵损失函数"""
    # pred的形状：(batch_size,num_steps,vocab_size)
    # label的形状：(batch_size,num_steps)
    # valid_len的形状：(batch_size,)
    def forward(self, pred, label, valid_len):
        weights = torch.ones_like(label)
        weights = sequence_mask(weights, valid_len)
        self.reduction='none'
        unweighted_loss = super(MaskedSoftmaxCELoss, self).forward(
            pred.permute(0, 2, 1), label)
        weighted_loss = (unweighted_loss * weights).mean(dim=1)
        return weighted_loss
    
#填充不计算损失
```
