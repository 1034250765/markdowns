# 模型诊断基础

> 来源：吴恩达《Machine Learning Specialization》P70–78（ML 策略/错误分析模块）

## 模型评估

### 为什么需要评估

训练误差（模型在训练集上的表现）**不能**反映真实能力——模型可能只是"背下了"训练数据。我们真正关心的是**泛化能力**：在没见过的数据上表现如何。

### 数据集三分法

| 数据集 | 用途 | 什么时候用 |
|--------|------|-----------|
| 训练集 Training set | 拟合模型参数（w, b） | 训练过程中，反复使用 |
| 交叉验证集 Cross-validation set（也叫 dev set / 验证集） | 选模型、调超参数 | 选模型/调参时，反复使用 |
| 测试集 Test set | 估计最终泛化性能 | **只在最后用一次** |

典型划分比例：
- 小数据集（1k~10k 条）：60% / 20% / 20%
- 大数据（百万级）：98% / 1% / 1%（验证集够用即可，不需要按比例留）

### 模型选择流程（为什么要三段划分）

假设要从 10 个候选模型（不同次数的多项式、不同超参数等）里选一个：

1. 用**训练集**分别训练 10 个模型
2. 用**交叉验证集**计算每个模型的验证误差，选验证误差最小的模型 d
3. 用**测试集**评估这个选出来的模型，报告它的泛化误差

关键点：如果直接用测试集来选模型，测试集就"泄露"了选择信息——它变成了变相的训练数据，报告的测试误差会**过度乐观**。验证集的作用就是充当"可选模型的考官"，把测试集保护起来。

> 换句话说：**验证集可以反复看，测试集只看一次。** 测试集上的数字是给最终汇报用的，不是用来做决策的。

### 常用评估指标

- 回归：均方误差 MSE、均方根误差 RMSE、平均绝对误差 MAE
- 分类：准确率（倾斜数据集下会失真，见下节；精确率/召回率详见《ML策略与错误分析.md》）
- 目标检测：mAP@0.5 / mAP@0.5:0.95（我们 benchmark 实验用的就是这个）

### 倾斜数据集下，准确率会失真

倾斜数据集（skewed dataset）= 类别占比极度不平衡。例：罕见病筛查，10000 人里仅 30 个阳性（0.3%）。此时准确率会**奖励偷懒的模型**：

| 模型 | 行为 | 找到病人 | 准确率 |
|---|---|---|---|
| A：全预测阴性 | 一个都不报 | 0 / 30 | **99.7%** |
| B：真干活 | 报出 124 人，其中 24 个真病人 | 24 / 30 | 98.9% |

B 明显更有用（80% 的病人被抓到，代价是 100 个误报人工复核），准确率却判 A 更好。失真的本质：阴性占 99.7%，准确率几乎完全由"把多数类判对"贡献，少数类的表现被彻底淹没；极端情况下模型只要"无脑报阴性"就能刷高指标。

一句话：**平衡数据集上准确率可信；倾斜数据集上必须换用只盯少数类的指标（精确率/召回率）。**

（对应我们：目标检测不用"像素级准确率"而用 mAP，同理--一张图里背景像素占绝对多数，不能让多数类淹没对前景的评估。）

### 训练误差 vs 验证误差——诊断的起点

| 情形 | 训练误差 | 验证误差 | 诊断 |
|------|---------|---------|------|
| 高偏差（欠拟合） | 高 | 高（两者接近） | 模型太简单 / 特征不够 |
| 恰到好处 | 低 | 低（接近训练误差） | — |
| 高方差（过拟合） | 很低 | 明显高于训练误差 | 模型记住了训练集的噪声 |

这一"看两个误差的绝对值 + 差距"的思路，是下面偏差/方差诊断的基础。

## 诊断偏差与方差（P73）

### 先有基准，才谈高低

"误差高不高"不是绝对的，要**和基准性能水平（baseline）比**：

- 人类在该任务上的水平（比如人眼识别准确率 99%）
- 竞品模型 / 已有系统的水平
- 任务本身的上限（图像太模糊、标注噪声等不可约误差）

例：语音识别训练误差 10.6%，听起来很高；但人类听同一段嘈杂语音的误差也是 10.5%，那它其实已经很接近上限了。

### 诊断表

设基准误差为 baseline：

| 诊断 | 训练误差 | 验证误差 | 判断依据 |
|------|---------|---------|---------|
| 高偏差（欠拟合） | 明显高于 baseline | ≈ 训练误差（也高于 baseline） | 两个都高且接近：连训练集都没学好 |
| 高方差（过拟合） | 接近/低于 baseline | **明显高于训练误差** | 训练学得好但泛化差：差距大 |
| 双高 | 高于 baseline | 更高 | 同时欠拟合 + 过拟合（小数据 + 复杂模型） |

### 正则化与偏差/方差（P74）

正则化强度 λ 直接控制模型在偏差-方差之间的位置：

| λ | 效果 | 偏向 |
|---|------|------|
| 太大 | w 被压向 0，模型过度简化 | 高偏差（欠拟合） |
| 合适 | - | 恰到好处 |
| 太小（->0） | 正则化失效 | 高方差（过拟合） |

**选 λ 的流程**：取一组候选值（0, 0.01, 0.02, 0.05, 0.1, 0.2, ...，常按 ~10 倍步长），每个 λ 训练一个模型 -> 用**验证集**选验证误差最小的 λ -> 最后用测试集报告一次。

（对应我们训练时调的 weight_decay、数据增强强度，同理都是拿 val 指标选。）

## 学习曲线（P76）

横轴：训练集大小；纵轴：误差。画两条曲线：训练误差（数据越多越高）和验证误差（数据越多越低）。

### 高偏差的学习曲线

```
误差 ▲
     │  baseline ───────────────
     │   ╲          ＿＿＿＿＿＿＿  验证误差
     │    ╲＿＿＿＿／
     │      训练误差（很快贴合验证误差，且都停在 baseline 之上）
     └──────────────────────────► 训练集大小
```

两条曲线快速贴合、都停在 baseline 之上--**加数据没用**（曲线已经平了），该做的是加大模型 / 加特征 / 减小 λ。

### 高方差的学习曲线

```
误差 ▲
     │  baseline ───────────────────
     │            ＼        ｜gap｜
     │             ＼＿＿＿＿＿＿＿＿   验证误差（还在下降）
     │  ＿＿＿＿＿＿／
     │  训练误差（一直很低）
     └────────────────────────────► 训练集大小
```

训练误差和验证误差之间有明显 gap，且验证误差还在随数据下降--**加数据有用**，也可以用正则化收窄 gap。

一句话：**学习曲线回答"该加数据还是该换模型"**，不用真把数据加满就能预判趋势。

## 决策表：决定下一步尝试什么（P77）

整个模块的精华，把前面所有诊断汇总成一张表：

| 诊断 | 该做什么 | 没什么用的 |
|------|---------|-----------|
| **高偏差**（欠拟合） | 更大的网络 / 训练更久 / 换更好的架构 / 增加相关特征 / 减小 λ | 盲目加数据 |
| **高方差**（过拟合） | 更多数据 / 数据增强 / 增大 λ / 换架构 | 加大模型 |

先诊断（看训练/验证误差 vs baseline，必要时画学习曲线），再按表行动，避免"盲调"。

## 偏差、方差与神经网络（P78）

传统机器学习讲究偏差-方差权衡（模型大了方差就高，只能折中）。现代深度学习改变了这一点：

- **更大的网络几乎不增加偏差**（只要正则化配合得当）
- **更多的数据几乎不增加偏差，且持续降低方差**
- 所以现代默认策略：**足够大的网络 + 合适的正则化 + 尽可能多的数据**，两头一起压

代价：训练所需的算力和时间。这也是为什么 YOLO 等模型越做越大、靠大规模预训练数据撑着泛化性。
