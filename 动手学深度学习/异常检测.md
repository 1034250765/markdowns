# 异常检测

> 来源：吴恩达《Machine Learning Specialization》P108–113（无监督学习模块·异常检测），与《模型诊断基础.md》《ML策略与错误分析.md》配套阅读

异常检测回答的是另一类问题：手头几乎只有正常样本、异常种类无法穷举时，怎么发现"不对劲"。本篇从问题设定与高斯建模（P108–109）走到完整算法（P110）、系统评估（P111）、与监督学习的选择标准（P112），最后落在特征工程（P113）；ε 的选法直接复用《ML策略与错误分析.md》的精确率/召回率工具箱。

## 发现异常事件（P108）

### 问题设定
异常检测（Anomaly Detection）：训练集**几乎全是正常样本**（没有或极少异常标签），从中学出"正常长什么样"，对每个新样本算一个**概率密度** p(x)——注意是密度不是概率，取值可以大于 1（σ 很小时曲线峰值能超过 1），这也是 ε 常取 0.001 这类小数却仍能工作的原因。
> p(x) 高 → 正常；p(x) 低 → 异常。**学的是"正常的形状"，不是"异常的样子"。**

### 课程例子：飞机发动机质检
工厂有 m 台正常发动机，每台抽特征（例如 x1 = 发热量 heat、x2 = 振动强度 vibration）。新下线的发动机 x_test 算 p(x_test)：低于 ε → 送去做详细测试（测试贵，所以只挑可疑的）；否则 → 放行。

### 其他应用
| 场景 | 特征 x（例如） | p(x) 低意味着 |
|------|----------------|----------------|
| 欺诈检测 fraud detection | 消费频率、登录地点等用户行为 | 可疑交易/盗号 |
| 数据中心机器监控 | 内存占用、CPU 温度、磁盘读写 | 机器可能快出故障 |

### 密度估计（Density Estimation）
形式化：给训练集拟合概率密度 p(x)，这一步叫密度估计，判断规则就一行——

```text
p(x_test) ≥ ε  →  正常（normal）
p(x_test) <  ε  →  异常（anomaly）
```

ε（epsilon）是阈值：调低则报异常更少更准，调高则漏检更少——和《ML策略与错误分析.md》里调阈值是同一种权衡；ε 怎么在开发集上定、系统怎么评估，P111 讲。

p(x) 的大致形状（大多数样本挤在峰附近，离群点掉到阈值以下；异常区 = 曲线掉到 ε 以下的左右两段尾部）：

```text
p(x)
 |              ____
 |            /    \
 |           /      \
 |----------/--------\--------------------------  ← ε（阈值线，横贯全图）
 |_________/          \__________________________
 +----------------------------------------------------→ x
  异常区 p(x) < ε    大多数样本 p(x) ≥ ε     异常区 p(x) < ε
    （左尾）                                     （右尾）
```

（对应我们：跨域测试集里的夜间牧场、严重遮挡，对检测器就是掉出训练分布的区域——跨域 mAP 掉多少，某种意义上是在量 p(x) 掉了多远。）

## 高斯正态分布（P109）

### 定义
高斯分布（Gaussian Distribution）即正态分布（Normal Distribution），钟形曲线，记 x ~ N(μ, σ²)：

```text
p(x; μ, σ²) = 1/(√(2π)·σ) · exp( −(x−μ)² / (2σ²) )
```

- μ（均值 mean）：曲线中心位置，越大整体越往右移
- σ（标准差 std）与 σ²（方差 variance）：曲线宽度，σ 越大越矮胖
- 曲线下总面积恒为 1

### 正态经验法则（68-95-99.7）
约 **68%** 样本落在 μ ± 1σ 内，约 **95%** 在 μ ± 2σ 内，约 **99.7%** 在 μ ± 3σ 内。
所以 3σ 之外只剩约 0.3%——"离均值远"天然等于"概率小"，这是异常检测敢拿 p(x) 当判据的直觉来源。

### 参数估计（Parameter Estimation）
拿到 m 个样本 {x^(1), …, x^(m)}，直接算：

```text
μ  = (1/m) · Σ x^(i)
σ² = (1/m) · Σ (x^(i) − μ)²
```

**注意口径**：课程用 1/m，统计教材的无偏估计是 1/(m−1)。m 大时两者几乎没差，但写代码要留意——`np.std` 默认 ddof=0（即 1/m，同课程），`pandas` 的 std 默认 ddof=1。

（对应我们：统计牛只标注的 bbox 面积/长宽比分布，估出 μ、σ 后把 3σ 外的极端框拎出来人工复核，就是最朴素的一版"异常检测式"数据清洗。）

一句话：**拟合 p(x) 的全部工作就是估两个数：μ 定位置，σ 定宽度。**

## 异常检测算法（P110）

接 P109 的高斯分布（Gaussian Distribution）：把 n 个特征的边缘密度（marginal density）连乘，就得到完整的异常检测（Anomaly Detection）算法，课程也称密度估计（Density Estimation）——只用正常样本拟合"正常长什么样"，新样本概率太低就报异常。

### 四步流程

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| 1 | 选特征 x_1..x_n | n 个特征的取值 |
| 2 | 对每个特征 j，用正常样本拟合 μ_j（均值）与 σ_j²（方差） | n 组 (μ_j, σ_j²) |
| 3 | 对新样本逐特征算密度，再连乘得联合概率 p(x) | 一个概率值 |
| 4 | p(x) < ε 判为异常（anomalous） | 异常标记 |

```
μ_j  = (1/m) · Σ x_j^(i)
σ_j² = (1/m) · Σ (x_j^(i) − μ_j)²

p(x_j; μ_j, σ_j²) = 1/(√(2π)·σ_j) · exp( −(x_j − μ_j)² / (2σ_j²) )

p(x) = p(x_1; μ_1, σ_1²) × p(x_2; μ_2, σ_2²) × … × p(x_n; μ_n, σ_n²)
```

第 3 步隐含一个假设：**各特征相互独立，联合密度 = 各边缘密度的乘积**。真实特征常有相关性，这是简化，但课程实践中够用。

### 直观图示

```
p(x_j)
  ^
  |               ___
  |             /     \
  |            /       \
  |  ~ ~ ~ ~ ~/ ~ ~ ~ ~ \~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~   <- ε（概率阈值）
  |          /           \
  |_________/             \__________________________
  +---------------------------------------------------> x_j
    异常区  |     正常区      |        异常区
              （曲线低于 ε 线的两侧尾部判为异常）
```

### 数值感受

以 σ=1 为例，取两个特征：一张正常图两项都落在 μ±1σ 内，单特征密度 0.24–0.40，连乘 p(x) ≈ 0.06–0.16（10^-1 量级）；一张过曝且模糊的图两项都掉到 μ±4σ 以外的尾部，单特征密度约 10^-4，连乘 p(x) ≈ 10^-8 量级。若取 ε = 10^-4，正常图比 ε 高约三个数量级，异常图比 ε 低约四个数量级，稳判异常。
**正常样本 p(x) 较大，异常样本 p(x) 远小于 ε。**

### ε 的语义

ε 是概率阈值，控制判异常的松紧：

| ε 调大 | ε 调小 |
|--------|--------|
| 更容易判异常，误报（false positive，正常被当异常）变多 | 更难判异常，漏报（false negative，放过真异常）变多 |

这与分类里调判阳阈值是同一类权衡，但方向相反：判阳阈值调大→判阳更严、误报变少；ε 调大→判异更松、误报变多。权衡逻辑同《ML策略与错误分析.md》的阈值权衡一节；ε 具体怎么选、系统怎么评估，见下一节 P111。

### 思路定性

拟合 p(x) 只需要"正常"样本（或以正常为主的样本），不需要异常标签就能训练；但选 ε 得靠放了少量带标签异常样本的交叉验证集（见 P111）——所以异常检测是**用无/弱监督数据做质量监控的工具**，路数和《模型诊断基础.md》里依赖 y 标签的偏差/方差诊断不同。
一句话：**异常检测学的是"正常长什么样"，而不是"异常长什么样"。**

（对应我们的数据集工作：把每张牛图的亮度均值、拉普拉斯方差（模糊度）、宽高/分辨率当特征，对清洗后的主批次拟合 μ、σ²，就能在标注前自动筛出过曝、模糊、异常尺寸的图。受独立性假设影响，模糊和亮度这类相关特征会被重复计权，特征宜少而互补。）

## 开发和评估异常检测系统（P111）

### 有少量标签时：三段式数据划分

异常检测 Anomaly detection 平时被当成无监督任务，但**手里只要有少量已标注的异常样本（y=1），就值得用它们做系统评估**——划分方式回到《模型诊断基础.md》P70 的数据集三分法：

| 数据集 | 正常样本 (y=0) | 异常样本 (y=1) | 用途 |
|--------|---------------|---------------|------|
| 训练集 Training set | 大量 | 极少，可有可无 | 只拟合 p(x)（各特征的 μ、σ²），**不参与任何评估** |
| 交叉验证集 Cross-validation set | 中等 | 少量 | **异常样本与测试集各分一批**：扫 ε、算 F1、调特征 |
| 测试集 Test set | 中等 | 少量（与 CV 不重叠的另一批） | **只在最后评估一次** |

> 训练集只用（无标签的）正常样本学"正常长什么样"，拟合 μ、σ² 用不到任何标签；就算混进极少量异常，也只是被当正常样本一起计入估计——**异常样本的价值在 CV 和测试集上兑现**。
> （Ng 也提到有的实践者干脆不分 CV 和测试、调参与评估混用一套数据——不推荐，守住两篇配套笔记共用的"测试集只看一次"老规矩。）

### 选阈值 ε

p(x) 有了之后，"p(x) < ε 判为异常"（P110 的判定规则）里的阈值 Threshold ε 本质是超参数——**不拍脑袋定，在 CV 集上扫**：

```text
ε ∈ {ε₁, ε₂, ε₃, …}   按数量级递减取一串候选（例如从 10⁻² 到 10⁻¹⁰）
for ε in 候选集:
    在 CV 集上预测 y = 1{p(x) < ε}
    算 Precision / Recall / F1
取 F1 最高的 ε
```

- **为什么不用准确率 Accuracy**：极度倾斜时全预测"正常"就能拿虚高的准确率——《ML策略与错误分析.md》P85 的同款教训
- **为什么用 F1**：调大调小 ε 会让精确率 Precision 与召回率 Recall 此消彼长，F1 帮你选折中——就是 P85-86 的阈值权衡套路

**一句话：ε 不是拍出来的，是在 CV 集上按 F1 扫出来的。**

（对应我们：这和给 YOLO 选置信度阈值 conf threshold 完全同构——扫 conf 找 P/R 平衡点，而不是吃默认值。）

## 异常检测与监督学习的对比（P112）

同样是"判断一个样本是不是问题"，两套框架怎么选？关键看**正样本的量和形态**：

| 维度 | 异常检测 Anomaly detection | 监督学习 Supervised learning |
|------|---------------------------|------------------------------|
| 正样本 (y=1) 数量 | 极少（例如 0~20 的量级） | 大量 |
| 负样本 (y=0) 数量 | 大量 | 大量 |
| 未来的异常/正样本形态 | 异常类型五花八门，**未来的异常可能与见过的完全不同** | **未来的正样本与训练集里的相似** |
| 典型应用 | 欺诈检测、制造质检、机器监控 | 垃圾邮件过滤、天气预报、疾病诊断 |

机制上的根源：异常检测对"正常"建模 p(x)，只学一类分布，所以天然能对没见过的异常报警；监督学习直接学正负边界，正类形态没见过就认不出。

**判断口诀：正样本少且形态多变 → 异常检测；正样本多且模式稳定 → 监督学习。**

- 分类不是永久的：欺诈等场景正样本攒多了、形态稳定了，完全可以转成监督学习
- （对应我们：表中"未来的异常/正样本形态"一行——"未来正样本与训练集相似"正是跨域 benchmark 打破的假设——4 个跨域测试集的牛只分布与训练集不同，mAP@0.5 的掉点量恰好量化了这个假设被破坏的程度。）

## 选择使用哪些特征（P113）

算法、评估、框架怎么选都齐了，最后一块拼图是特征：p(x) 建得准不准，很大程度上取决于每个特征的分布形状。

### 特征假设：先让特征"像高斯"
异常检测（P110）默认各特征**近似高斯正态分布（Gaussian / Normal distribution）**——形状越接近钟形，p(x) 建得越准。
检查手段：对每个特征画**直方图（histogram）/ 密度图**。

不像高斯先做变换，再重画直方图确认形状：

```
x' = log(x + c)    # 右偏长尾首选；c 为小常数，保证 x + c > 0
x' = x ** 0.5      # 候选变换之一（温和压缩）
x' = x ** 0.1      # 候选变换之一（指数越小，对长尾压缩越狠）
```

方法并不唯一：都试一遍，各自重画直方图，挑最接近钟形的那个。

一句话：**拿到特征先画直方图，不像高斯就先变换，别直接硬套算法。**

### 异常检测的错误分析（error analysis）
与监督学习同理（见《ML策略与错误分析.md》），异常检测同样由"看错题"驱动改进：

```
验证集上发现漏报（false negative）：实际是异常，但 p(x) 并不小
        ↓
观察这批样本：它们身上有什么信息，是现有特征没覆盖到的？
        ↓
新增 / 改造特征，把这类异常从正常分布中"挤出去"
        ↓
回到 P111 流程：重新评估 + 用 F1 选阈值
```

### 组合行为异常：单一特征看不出的问题
课程例子（数据中心监控）：某台机器异常时，**CPU 负载偏高，同时网络流量异常低**。

```
x2 = 网络流量
 ^
 |                        ● ● ●   正常样本云
 |                   ● ● ●        （负载与流量正相关，沿对角线分布）
 |              ● ● ●
 |         ● ● ●
 |    ● ● ●
 |
 |                            X  异常机器（x1 偏高 + x2 偏低）
 +-------------------------------> x1 = CPU 负载
```

正常机器上 CPU 负载与网络流量同涨同跌（近似线性关系），样本云沿主对角线分布。

- 单看 CPU：仍在正常范围内（至多是边缘值）
- 单看流量：同样在正常范围内
- 组合起来：明显异常——落在正常样本云之外

因此任何单一特征的 p(x) 都不会小；需要新增**能捕捉特征组合关系**的新特征。课程给的公式（MLS 2022 幻灯片）：

```
x3 = x1 ** 2 / x2    # = (CPU 负载)² / 网络流量
```

（2012 版课程为 `x5 = x3 / x4` = CPU 负载 / 网络流量。）

直觉：正常机器上负载与流量同涨同跌，x1²/x2 大致稳定，仍落在正常分布内；死循环 / 异常机器负载高、流量低，x3 异常大——落出正常分布，p(x) 很小，从而被判为异常。

### 特征选择准则
一句话：**选特征的标准：让正常样本的 p(x) 大、让异常样本的 p(x) 小。**

直觉：特征不是越多越好——每加一个都问"它能否把某类异常从正常云里分出去"；有标签时（P111 / P112），验证集上的漏网异常就是现成的检验标准。

### 联系我们：数据集体检
把异常检测用在数据集监控上：对每张图取

```
[亮度均值, 模糊度, 目标框数量, 目标长宽比, ...]
```

作为特征，拟合 p(x) 后筛出低概率样本——大概率是过暗 / 过曝、严重模糊、框数异常（漏标或异常密集）的坏样本，人工确认后再决定去留（对应我们 4 个跨域测试集进 benchmark 前的质量筛查）。

一句话：**好特征 = 能把异常挤出正常分布的特征。**
