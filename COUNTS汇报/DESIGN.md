# COUNTS 论文汇报 · 设计稿

## 1. 风格定位

- **基础风格**：命中学术风预设（科研论文汇报场景），但按用户偏好"明亮活泼"做微调：
  - 用更明亮的浅蓝基底 + 渐变主色 + 明黄/蜜橙作为点睛强调；
  - 保留蓝白克制、证据驱动、文字优先的学术本质；
  - 去掉标准学术风的深灰、严肃卡通字、满屏严肃压暗；
  - 增加呼吸感与图形化（标签云、流程胶囊、KPI 三联数）。
- **可视化基调**：蓝紫渐变主色（#1E4FA8 → #5B7FCE），明黄（#FFC247），薄荷绿（#3CC9A1），蜜橙（#FF8A4C）。

## 2. 画布与母版

- **画布**：1280 × 720（标准 16:9）
- **安全边距**：左右 40，顶部 24，底部 24
- **页眉模式**：A3（深蓝顶条 + 低透明校园/科研线稿），全篇统一
- **页脚**：左下"COUNTS · 跨域目标检测与多模态 grounding" 14px 灰色；右下页码 "页码 / 18"
- **章节扉页可省 A/D**：第 1、3、6、10、16、18 页只用 C 区极简主体（保留底部细线 logo + 页码）

## 5. 信息密度与可读性

- 内容页 C 区累计高 ≥ 470px，宽 = 1200px；元素不得集中在中央 60% 区域。
- 卡片填充率 ≥ 75%；卡尾数字、标签锚底；兄弟卡高差 ≤ 8px。
- 卡内 padding：上下 16，左右 ≥ 20；正文必须允许软换行。
- 文字对比度 ≥ 4.5:1；蓝底放白字，白底放深蓝/深灰。
- 全篇正文页组件 ≥ 3 类，修辞 ≥ 4 种，层次 ≥ 3 层。
- 仪式段（扉页/Hero）留白 ≤ 40%；内容页禁大留白。

## 6. 配图与组件

### 配图等级

| 等级 | 用途 | 规则 |
|------|------|------|
| L1 主视觉 | 数字卡、流程图、SVG 标签云、双折线图、分组柱状图 | 双栏 ≥ 35%，大图 ≥ 50% |
| L2 支撑图 | 论文 link 框、来源 chip | ≥ 240×160 |
| L3 角标 | 学术 logo（TSINGHUA / 论文 chip） | ≤ 64×64 |

全篇 L1 视觉以**数据图表 / SVG 流程 / KPI 卡**为主，不用营销插画或 3D。

### 组件族

- **标签 / 编号**：浅蓝药丸、深蓝编号方块、亮青 chip、明黄高亮标签、蜜橙警示药丸
- **标题 / 金句条**：深蓝标题条（左 8px 竖条 + 标题）、底部强调条、核心金句条（单页 ≤ 1，全篇 ≤ 4）
- **卡体**：默认浅描边卡（1px #D6DCE5）、柔和阴影卡（凸显单卡）、深蓝实色卡（单页 ≤ 1，全篇 ≤ 3，多卡页禁用）
- **流程连接**：节点串、胶囊步骤、箭头、共享外框
- **数据强调**：KPI 三联数、表格高亮、圆环进度、引文符号块、Tag Cloud

### 卡内五段骨架

常规正文卡优先包含：S1 标题条、S2 引导句、S3 主体正文、S4 关键数据/引文、S5 尾部标签。S1/S3/S4 必填，S4 锚底。

## 7. 页面类型规则

### 封面 (P1)
- 中央顶部：浅蓝渐变背景条（顶 200px 渐变 #1E4FA8 → #5B7FCE）
- 中央：英文论文标题衬线字（24px Times Bold）+ 中文主标（72px Bold 黑）
- 副标：作者机构 + 论文链接 chip（亮青底）
- 底部：三段 meta 排（汇报日期 / 单位 / 汇报人），用蜜橙色细线分隔

### 目录 (P2)
- 左 30%：大块深蓝色"目录 / Catalog"字（96px Bold）+ 章节计数（亮青药丸）
- 右 70%：5 条目编号列表（深蓝编号方块 + 中文标题 + 一行英文注解）

### 章节扉页 (P3, P6, P10, P16)
- 中央：左 60% 大数字或金句（96-200px Bold），右 40% 描述卡片
- 底部：横向进度条（显示当前章节位置）
- 顶部细线：当前章节名（深蓝 14px）

### 正文
- **P4（5b 三栏）**：左 22% 标题区，中 78% 三张同款卡，每卡一个关键词 + 主题色横条
- **P5（5h 关键词矩阵）**：上 2×3 矩阵（含色彩百分比 chip），下底部强调条
- **P7（非对称双栏）**：左 55% 四个 KPI 巨型数字 2×2 网格，右 35% 洞察卡
- **P8（左大图+右侧文字）**：左 60% SVG 标签云图（14 个域分类），右 35% 三段式描述卡
- **P9（四胶囊横排）**：横向四胶囊节点串（候选筛选 → 验证 → 标注 → 复核），下方单卡结论
- **P11（左标题+右 2×2）**：左 30% 标题 + 6 个目标域 chip；右 70% 2×2 矩阵（每个矩阵含详细偏移类型）
- **P12（非对称三栏）**：5 种评测设置横向分行（标签 + 一段话），下方三类任务卡
- **P13（图表+洞察）**：上分组柱状图 + 下方表 2 摘要 + 右侧洞察卡
- **P14（非对称双栏）**：左 55% 双折线图 + 右 40% 关键发现文字
- **P15（非对称双栏）**：左右两个对比卡（GPT-4o vs Gemini），下方共同结论条
- **P17（上大图+下方三卡片）**：上 50% 应用场景 SVG 示意（自动驾驶/机器人/监控），下三卡片纵列说明

### 致谢 (P18)
- 中央：居中"Q&A"或"感谢聆听"（120px Bold）
- 下方：三条 meta 行（论文 / 代码 / 数据链接），亮青 chip 样式
- 底部细线：机构 chip + 论文 chip

## 8. 反复使用的图形元素（一致性）

- **数据 chip**：圆角矩形（rx=8），浅蓝底 #E8EFF8 + 深蓝文字
- **目标域 chip**：圆角矩形（rx=4），明亮渐变底 + 深蓝文字 + 类别序号
- **强调金句框**：圆角矩形（rx=12），2px 深蓝边框 + 浅黄底 #FFC247 20% + 文字
- **KPI 单元**：圆角矩形（rx=12），白底 + 1px 描边 + 上方数字（>84px Bold）+ 下方标签（16px Regular）
- **流程节点**：圆 + 数字 + 名称，垂直连接线 2px
- **折线图标记点**：圆点（直径 10px）+ 数值标签
- **柱状图柱**：圆角顶（rx=4），主色渐变

## 9. 自检硬闸门

1. 内容页 C 区累计高 < 470px 或留白明显过大 → 返工
2. 任何页面 C 区出现深色实底或高饱和彩色实底 → 返工
3. 红 + 黄 > 5%，金色出现，使用禁色 → 返工
4. 字号低于下限（正文 < 18px、卡内标题 < 22px） → 返工
5. 卡片缺 S1/S3/S4 → 返工
6. 深蓝实色卡超过 3 张或多卡页使用多张 → 返工
7. N 卡片横排出现 ≥ 3 次 → 返工
8. 连续两页相同版式 → 返工
9. 文字溢出卡片、断词异常、对比度 < 4.5:1 → 返工
10. 页眉/页脚 / LOGO / 页码全篇不一致 → 返工
11. 数据图缺主图、洞察或关键数字 → 返工
